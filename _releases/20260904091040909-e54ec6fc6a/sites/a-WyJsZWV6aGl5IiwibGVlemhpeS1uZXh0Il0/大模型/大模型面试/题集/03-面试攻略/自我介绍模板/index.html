自我介绍模板

1. 一、自我介绍的核心原则

2. 二、1 分钟版本（快速介绍）

2.1. 模板结构

[问候] + [我是谁] + [核心优势] + [为什么适合这个岗位]

2.2. 模板（应届/转行者）

面试官您好，我是 [姓名]，[学校/背景] 毕业，专业是 [专业]。

我对 AI Agent 领域充满热情，[时间段] 开始系统学习大语言模型和 Agent 技术，
独立完成了 [项目名] 等项目，熟悉 ReAct、RAG、Function Calling 等核心技术。

我具备扎实的 Python 编程基础和快速学习能力，
对贵公司的 [某个产品/方向] 非常感兴趣，希望能加入团队贡献价值。

2.3. 模板（有经验者）

面试官您好，我是 [姓名]，[X] 年 AI/软件开发经验，
其中 [X] 年专注于大模型应用开发。

我在 [上家公司] 负责 [Agent 相关的工作]，
主导/参与了 [项目名]，实现了 [成果，用数据量化]。

我精通 LangChain/LlamaIndex 等 Agent 框架，
具备从 0 到 1 构建生产级 Agent 系统的经验，
希望能将我的经验应用到贵公司的 [某个方向]。

3. 三、3 分钟版本（详细介绍）

3.1. 模板结构

1. 开场（10秒）
2. 教育背景（30秒）
3. 工作经历/项目经验（90秒）
4. 技术亮点（30秒）
5. 应聘动机（20秒）

3.2. 完整模板（有经验者）

【开场】
面试官您好，我是 [姓名]，很高兴参加今天的面试。

【教育背景】
我毕业于 [学校]，[专业]，[时间段] 期间 [学术成就/相关课程]。

【工作经历】
毕业后我加入了 [公司名]，担任 [职位]，主要负责 [职责描述]。
在此期间，我主导了 [项目 A]，这是一个 [项目描述]，
我负责 [具体工作]，最终实现了 [成果，数据量化]。

之后我加入了 [公司名]，开始专注于大模型应用开发。
我参与搭建了公司的 AI Agent 平台，支持 [功能描述]，
服务了 [X] 个业务场景，日均调用量达到 [X]。

【技术亮点】
在技术方面，我精通 LangChain 和 CrewAI 框架，
深入理解 ReAct、CoT、RAG 等 Agent 核心技术原理，
具备 MCP 协议和 Function Calling 的实战经验。
我关注行业动态，在 GitHub 维护了一个 [X stars] 的开源项目。

【应聘动机】
了解到贵公司在 [某个方向] 的深耕，
这与我的技术栈和职业发展方向高度契合，
希望能有机会加入团队，共同推动 Agent 技术的应用落地。

4. 四、不同经验级别模板

4.1. 应届毕业生

面试官您好，我是 [姓名]，来自 [学校] [专业] 应届毕业生。

在校期间，我系统学习了机器学习和深度学习课程，
对 NLP 和大语言模型有浓厚兴趣。
我自学了 LangChain 框架，完成了一个 [项目描述] 的项目，
实现了 [具体功能]，代码开源在 GitHub 上。

我积极参与技术社区，[具体贡献]。
虽然缺乏正式工作经验，但我学习能力强，
对 Agent 技术有深入的理解和实践经验，
相信自己能快速适应并为团队做出贡献。

4.2. 1-3 年经验

面试官您好，我是 [姓名]，[X] 年 Python 开发经验，
近 [X] 年专注于大模型应用开发。

我在 [公司] 负责 [核心工作]，
完成了 [项目 1：描述+成果] 和 [项目 2：描述+成果]。
通过这些项目，我积累了 [RAG/Agent/工具开发] 的实战经验，
熟悉从开发到部署的完整流程。

我独立解决过 [某个技术难题]，
对 [某个技术点] 有深入的理解。
希望能加入贵团队，在更复杂的场景中发挥价值。

4.3. 3-5 年经验

面试官您好，我是 [姓名]，[X] 年 AI 领域经验，
其中 [X] 年深耕大模型应用和 Agent 技术。

我先后在 [公司 A] 和 [公司 B] 工作，
主导/核心参与了 [重点项目 1]、[重点项目 2]。
在 [项目 1] 中，我设计了 [架构/方案]，解决了 [痛点]，
带来了 [量化成果]。

我在团队中还承担了 [技术分享/代码审查/新人指导] 等工作，
具备一定的技术影响力。
希望能在贵公司更大的平台上，推动 Agent 技术的创新应用。

4.4. 年以上经验

面试官您好，我是 [姓名]，[X] 年技术经验，
近 [X] 年专注 AI Agent 和 LLM 应用架构。

我在 [公司] 担任 [技术负责人/架构师]，
负责 [技术方向] 的整体规划和落地。
主导设计了 [系统架构]，支撑了 [业务规模]。

我在 [技术领域] 有深度积累，
发表了 [论文/博客/演讲]，开源了 [项目]。
带领 [X] 人团队完成了 [重大项目]。

我对贵公司在 [方向] 的技术布局非常认同，
希望能带领团队推动 Agent 技术的突破。

5. 五、自我介绍注意事项

5.1. ✅ 应该做的

要点 说明
量化成果 "提升了 30% 的准确率" 比 "大幅提升了准确率" 更有说服力
突出相关经验 重点讲与 Agent 相关的项目和技术
展示热情 让面试官感受到你对这个方向的真正兴趣
眼神交流 与面试官保持适当的眼神接触
语速适中 不紧不慢，重点处适当停顿

5.2. ❌ 不应该做的

要点 说明
背诵感太重 要自然流畅，不要像背书
过于冗长 控制时间，不要超时
负面信息 不要抱怨前公司或同事
虚假信息 不要夸大或虚构经历
偏离主题 不要说与岗位无关的内容

6. 六、针对 Agent 岗位的调整建议

6.1. 关键词植入

确保自我介绍中包含以下关键词：

- Agent 框架: LangChain / LlamaIndex / CrewAI / AutoGen
- 核心技术: ReAct / CoT / RAG / Function Calling / MCP
- 模型: GPT-4 / Claude / 通义千问 / Llama
- 工程能力: Python / FastAPI / Docker / 向量数据库
- 项目经验: 从 0 到 1 / 生产环境 / 性能优化
