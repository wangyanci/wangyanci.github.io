Agent 架构分层设计

一、分层架构概述

生产级 Agent 系统采用分层架构设计，每一层职责清晰、接口明确，便于独立开发、测试和扩展。本文介绍业界通用的五层架构模型。

核心设计原则

1. 单一职责：每层只负责一类功能
2. 依赖倒置：上层依赖下层抽象，不依赖具体实现
3. 可替换性：每层实现可独立替换
4. 可观测性：每层都有完善的日志和监控

第一层：接入层（Input/Output Gateway）

负责处理所有外部输入输出，是系统的"门面"。

核心职责：

职责 说明 实现要点
协议适配 支持多种接入方式 HTTP/WebSocket/GRPC
身份认证 验证用户身份 API Key/JWT/OAuth
限流控制 防止系统过载 Token Bucket/滑动窗口
输入校验 防止注入攻击 Prompt 注入检测、长度限制
请求路由 分发到不同 Agent 按业务类型路由
格式化输出 统一输出格式 Markdown/JSON/Stream

接入层代码示例：

class InputGateway:
    """接入层：输入处理"""
    
    def __init__(self):
        self.rate_limiter = TokenRateLimiter(max_tokens=1000)
        self.prompt_guard = PromptGuard()
        self.auth = AuthManager()
    
    async def process_input(self, request: Request) -> ProcessedInput:
        # 1. 身份认证
        user = await self.auth.authenticate(request)
        
        # 2. 限流检查
        if not await self.rate_limiter.allow(user.id):
            raise RateLimitExceeded()
        
        # 3. 输入校验
        raw_input = request.text
        if len(raw_input) > MAX_INPUT_LENGTH:
            raise InputTooLong()
        
        # 4. 安全检测
        guard_result = self.prompt_guard.check(raw_input)
        if guard_result.is_injection:
            raise PromptInjectionDetected(guard_result.reason)
        
        # 5. 输入清洗
        cleaned = self.sanitize(raw_input)
        
        return ProcessedInput(
            user=user,
            text=cleaned,
            metadata=request.metadata,
            session_id=request.session_id
        )
    
    def sanitize(self, text: str) -> str:
        """清洗输入，移除潜在有害内容"""
        # 移除控制字符
        text = re.sub(r'[\x00-\x08\x0b-\x0c\x0e-\x1f]', '', text)
        # 规范化空白
        text = ' '.join(text.split())
        return text.strip()

多轮对话 处理复杂交互流程 状态跟踪、分支处理

第三层：Agent 核心层（Agent Core）

Agent 的"大脑"，负责推理、规划和决策。

核心职责：

职责 说明 关键组件
推理引擎 执行推理过程 ReAct/CoT/ToT 实现
规划器 任务分解和规划 子任务拆分、依赖管理
工具选择 选择合适工具 工具描述匹配、历史反馈
记忆管理 读写记忆 短期/长期记忆协调
反思机制 自我纠错 Reflexion、错误检测
Prompt 管理 模板管理和优化 动态模板、少样本示例

Agent 核心代码框架：

class AgentCore:
    """Agent 核心层"""
    
    def __init__(
        self,
        llm: LLM,
        memory: MemorySystem,
        planner: Planner,
        tool_registry: ToolRegistry
    ):
        self.llm = llm
        self.memory = memory
        self.planner = planner
        self.tools = tool_registry
        self.max_iterations = 10
    
    async def execute(self, task: Task) -> AgentResult:
        """执行 Agent 循环"""
        # 1. 规划任务
        plan = await self.planner.create_plan(task)
        
        # 2. 执行 ReAct 循环
        for i in range(self.max_iterations):
            # 检索相关记忆
            memories = self.memory.retrieve(task.query)
            
            # 构建上下文
            context = self._build_context(task, plan, memories, i)
            
            # LLM 推理
            thought = await self.llm.think(context)
            
            # 决策
            if thought.should_finish:
                return AgentResult(
                    answer=thought.answer,
                    reasoning=thought.reasoning
                )
            
            # 工具调用
            if thought.selected_tool:
                observation = await self.tools.execute(
                    thought.selected_tool,
                    thought.tool_input
                )
                self.memory.store_observation(observation)
        
        return AgentResult(
            answer="任务处理超时",
            reasoning="达到最大迭代次数"
        )

第四层：工具层（Tool Layer）

封装所有外部工具的调用接口。

核心职责：

职责 说明 关键实现
工具注册 统一管理工具 注册表、版本控制
Schema 管理 参数定义和校验 JSON Schema、自动校验
执行引擎 调用工具 异步执行、并发控制
沙箱环境 安全执行 容器化、权限隔离
错误处理 故障恢复 重试、降级、熔断
调用监控 可观测性 日志、指标、追踪

第五层：输出管控层（Output Guardrails）

确保 Agent 输出安全、合规、高质量。

核心职责：

职责 说明 检测方法
PII 检测 防止泄露个人信息 正则匹配/NER 模型
毒性检测 防止有害内容 分类模型
幻觉检测 防止编造内容 与检索结果比对
格式校验 确保输出格式正确 Schema 校验
敏感内容过滤 合规要求 关键词/模型检测
引用校验 确保引用准确 与源文档比对

输出管控代码示例：

class OutputGuardrails:
    """输出管控层"""
    
    def __init__(self):
        self.pii_detector = PIIDetector()
        self.toxicity_checker = ToxicityChecker()
        self.hallucination_detector = HallucinationDetector()
        self.format_validator = FormatValidator()
    
    async def check(self, output: str, context: dict) -> GuardResult:
        """执行所有检查"""
        violations = []
        
        # 1. PII 检测
        pii_result = self.pii_detector.check(output)
        if pii_result.has_pii:
            violations.append(Violation(
                type="PII",
                severity="high",
                details=pii_result.entities
            ))
        
        # 2. 毒性检测
        toxicity = self.toxicity_checker.score(output)
        if toxicity > TOXICITY_THRESHOLD:
            violations.append(Violation(
                type="toxicity",
                severity="high",
                details={"score": toxicity}
            ))
        
        # 3. 幻觉检测
        if context.get("retrieved_docs"):
            hallucination = self.hallucination_detector.check(
                output, 
                context["retrieved_docs"]
            )
            if hallucination.score > HALLUCINATION_THRESHOLD:
                violations.append(Violation(
                    type="hallucination",
                    severity="medium",
                    details={"score": hallucination.score}
                ))
        
        return GuardResult(
            passed=len(violations) == 0,
            violations=violations,
            sanitized_output=self.sanitize(output, violations)
        )
    
    def sanitize(self, output: str, violations: list) -> str:
        """清洗违规内容"""
        for v in violations:
            if v.type == "PII":
                output = self.pii_detector.redact(output, v.details)
        return output

四、层间交互关系

五、常见面试考点

Q1: 为什么 Agent 要采用分层架构？

答: 分层架构实现关注点分离，每层职责单一，便于独立开发、测试和扩展。同时支持团队并行开发，降低系统复杂度，提高可维护性。

Q2: 接入层需要处理哪些安全问题？

答:

  1. 身份认证和授权
  2. Prompt 注入攻击检测
  3. 输入长度限制
  4. 限流防刷
  5. 敏感词过滤

Q3: 输出管控层如何检测幻觉？

答:

  1. 将输出与检索到的文档进行语义比对
  2. 检查输出中的事实性陈述是否有来源支撑
  3. 使用专门的幻觉检测模型
  4. 要求模型标注引用来源
