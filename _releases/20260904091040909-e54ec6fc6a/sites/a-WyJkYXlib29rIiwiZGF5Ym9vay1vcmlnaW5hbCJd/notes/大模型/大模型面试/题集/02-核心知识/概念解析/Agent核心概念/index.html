Agent 核心概念

一、Agent 的定义

AI Agent（智能体/代理）是指能够感知环境、做出决策并执行动作以实现特定目标的自主系统。与传统的大语言模型（LLM）不同，Agent 具备以下核心特征：

特征 传统 LLM AI Agent
交互方式 单轮/多轮对话 自主循环执行
工具使用 无 可调用外部工具
记忆能力 无持久记忆 具备短期/长期记忆
规划能力 被动响应 主动规划与决策
目标导向 生成文本 完成具体任务

Agent 的核心定义公式

Agent = LLM + 规划能力 + 记忆 + 工具使用

Agent 的本质是：以大语言模型为"大脑"，通过循环执行"思考-行动-观察"的闭环，不断向目标逼近的系统。

二、Agent 的四大核心组件

1. 规划（Planning）

规划是 Agent 的"决策中枢"，负责：

  • 任务分解：将复杂任务拆解为可执行的子任务
  • 步骤规划：确定执行顺序和依赖关系
  • 反思与调整：根据反馈动态调整计划

规划技术演进：

技术 核心思想 适用场景
CoT 链式推理，逐步思考 数学计算、逻辑推理
ToT 多路径探索，维护候选方案树 决策问题、创意生成
GoT 图结构推理，支持聚合与循环 复杂关联问题
ReAct 推理与行动交替进行 工具调用、环境交互

2. 记忆（Memory）

记忆类型对比：

类型 存储位置 容量 持久性 检索方式
感觉记忆 模型上下文 非常有限（上下文窗口） 临时 直接读取
短期记忆 对话历史 有限 会话级 顺序读取
长期记忆 向量数据库 几乎无限 持久 向量相似度检索
程序记忆 模型权重 固定 永久 推理时激活

3. 工具（Tools）

工具是 Agent 与外部世界交互的"手臂"，使 Agent 能够：

  • 获取实时信息（搜索引擎、API）
  • 执行代码（代码解释器）
  • 操作外部系统（数据库、文件系统）
  • 专业计算（计算器、数学库）

工具调用的核心要素：

  1. 工具定义：用 JSON Schema 描述工具名称、参数、返回值
  2. 工具选择：LLM 根据当前任务选择合适工具
  3. 参数填充：LLM 生成工具调用所需的参数
  4. 结果观察：工具执行结果反馈给 LLM 进行下一步决策

4. 行动（Action）

行动是 Agent 执行决策并观察结果的环节。在 ReAct 框架中，行动包括：

  • 思考（Thought）：分析当前状态，制定下一步计划
  • 行动（Action）：调用工具或生成输出
  • 观察（Observation）：获取行动结果

三、Agent 的工作循环

工作循环的详细步骤

┌─────────────────────────────────────────────────────────────┐
│                    Agent 工作循环                             │
├─────────────────────────────────────────────────────────────┤
│  1. 【初始化】加载记忆、注册工具、设定目标                    │
│                     ↓                                        │
│  2. 【感知】从环境获取输入，查询相关记忆                      │
│                     ↓                                        │
│  3. 【思考】LLM 分析当前状态，制定计划                        │
│                     ↓                                        │
│  4. 【决策】选择下一步行动（工具调用或直接回答）              │
│                     ↓                                        │
│  5. 【执行】调用工具或生成响应                                │
│                     ↓                                        │
│  6. 【观察】获取执行结果                                      │
│                     ↓                                        │
│  7. 【判断】任务是否完成？                                    │
│         ├─ 未完成 → 返回步骤 2                                │
│         └─ 完成 → 步骤 8                                    │
│                     ↓                                        │
│  8. 【收尾】存储记忆，输出最终结果                            │
└─────────────────────────────────────────────────────────────┘

六、常见面试考点

Q1: Agent 和 LLM 的根本区别是什么？

答: LLM 是"大脑"，Agent 是"完整的人"。LLM 只能生成文本，而 Agent 具备规划、记忆、工具调用、自主循环四大能力，能够在环境中自主行动以完成任务。

Q2: Agent 的四大组件各自的作用？

答:

  • 规划: 拆解任务、制定执行计划
  • 记忆: 存储和检索经验，支持上下文理解
  • 工具: 扩展能力边界，与外部世界交互
  • 行动: 执行决策、获取反馈

Q3: 为什么 Agent 需要记忆机制？

答:

  1. 突破上下文限制: LLM 上下文窗口有限
  2. 跨会话学习: 长期记忆使 Agent 能积累经验
  3. 个性化: 记忆用户偏好和历史交互
  4. 连贯性: 保持多轮对话的上下文连贯
