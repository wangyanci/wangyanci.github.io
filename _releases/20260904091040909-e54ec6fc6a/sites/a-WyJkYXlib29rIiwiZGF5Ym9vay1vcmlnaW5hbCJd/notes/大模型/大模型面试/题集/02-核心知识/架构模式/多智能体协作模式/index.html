多智能体协作模式

一、多智能体系统概述

多智能体系统（Multi-Agent System, MAS）由多个 Agent 组成，通过协作、通信和协调完成单个 Agent 难以完成的复杂任务。

二、三大协作模式

三、层级模式（Hierarchical）

架构图

特点

维度 说明
结构 树形结构，Manager 统一管理 Workers
通信 上下级通信，Worker 间不直接通信
决策 Manager 集中决策
适用 任务可分解为明确子任务

工作流程

代码示例（CrewAI 风格）

from crewai import Agent, Task, Crew

# 定义 Manager
manager = Agent(
    role="项目经理",
    goal="协调团队完成软件开发任务",
    backstory="经验丰富的项目经理，擅长任务分解和进度跟踪",
    allow_delegation=True
)

# 定义 Workers
researcher = Agent(
    role="研究员",
    goal="调研技术方案",
    backstory="技术调研专家"
)

coder = Agent(
    role="程序员",
    goal="编写高质量代码",
    backstory="资深全栈工程师"
)

tester = Agent(
    role="测试员",
    goal="确保代码质量",
    backstory="测试专家，擅长发现边界问题"
)

# 定义任务
tasks = [
    Task(description="调研技术方案", agent=researcher),
    Task(description="实现核心功能", agent=coder),
    Task(description="编写测试用例", agent=tester)
]

# 创建 Crew
crew = Crew(
    agents=[manager, researcher, coder, tester],
    tasks=tasks,
    process="hierarchical"  # 层级模式
)

result = crew.kickoff()

五、竞争模式（Competitive）

架构图

特点

维度 说明
结构 生成器 + 评审器
通信 生成器独立工作，评审器统一评估
决策 评审器选择最优方案
适用 方案生成、代码生成、创意竞赛

六、三种模式对比

维度 层级模式 平等模式 竞争模式
结构 树形 网状 生成-评审
通信方式 上下级 任意点对点 单向提交
决策机制 集中决策 协商共识 评审择优
适用场景 任务分解明确 头脑风暴、讨论 方案生成
代表框架 CrewAI AutoGen Multi-Agent Debate
优势 结构清晰、易管理 灵活、创意丰富 质量高、可扩展
劣势 单点瓶颈 协调复杂 计算成本高

八、常见面试考点

Q1: 多智能体系统的三种协作模式？

答: 层级模式（Manager-Worker 树形结构）、平等模式（点对点网络结构）、竞争模式（生成器-评审器结构）。

Q2: 如何选择协作模式？

答: 任务分解明确选层级模式；需要多角度讨论选平等模式；需要生成多个方案择优选竞争模式。实际系统常采用混合模式。

Q3: 多智能体系统的挑战？

答:

  1. 通信开销大
  2. 协调复杂度高
  3. 调试困难
  4. 成本控制
  5. 一致性问题
