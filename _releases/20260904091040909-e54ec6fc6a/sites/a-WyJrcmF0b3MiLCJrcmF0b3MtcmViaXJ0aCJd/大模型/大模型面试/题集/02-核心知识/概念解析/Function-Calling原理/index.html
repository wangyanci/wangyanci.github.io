Function Calling 原理详解

一、Function Calling 概述

Function Calling（函数调用/工具调用）是大语言模型的核心能力之一，允许模型根据用户输入判断是否需要调用外部函数，并生成符合函数签名的参数。

核心定位

Function Calling 是 LLM 的"手"——让模型能够操作外部世界

为什么 Function Calling 重要？

二、Function Calling 的完整流程

三、Function Calling 的核心要素

1. 函数定义（Tool Definition）

使用 JSON Schema 描述函数签名：

{
  "type": "function",
  "function": {
    "name": "get_weather",
    "description": "获取指定城市的当前天气信息",
    "parameters": {
      "type": "object",
      "properties": {
        "city": {
          "type": "string",
          "description": "城市名称，如'北京'、'上海'"
        },
        "unit": {
          "type": "string",
          "enum": ["celsius", "fahrenheit"],
          "description": "温度单位"
        }
      },
      "required": ["city"]
    }
  }
}

2. API 调用结构

import openai

# 定义工具列表
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "获取指定城市的当前天气信息",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {
                        "type": "string",
                        "description": "城市名称"
                    }
                },
                "required": ["city"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "search_news",
            "description": "搜索新闻",
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {
                        "type": "string",
                        "description": "搜索关键词"
                    },
                    "limit": {
                        "type": "integer",
                        "description": "返回数量",
                        "default": 5
                    }
                },
                "required": ["query"]
            }
        }
    }
]

# 调用 API
response = openai.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "北京今天天气怎么样？"}
    ],
    tools=tools,           # 提供可用工具定义
    tool_choice="auto"     # 让模型自动决定是否调用
)

# 解析响应
message = response.choices[0].message

if message.tool_calls:
    # 模型决定调用函数
    for tool_call in message.tool_calls:
        function_name = tool_call.function.name
        arguments = json.loads(tool_call.function.arguments)
        print(f"调用函数: {function_name}")
        print(f"参数: {arguments}")

3. 函数执行与结果回传

# 执行函数并获取结果
def execute_function(name: str, arguments: dict):
    """根据函数名执行对应函数"""
    if name == "get_weather":
        return get_weather(**arguments)
    elif name == "search_news":
        return search_news(**arguments)
    else:
        raise ValueError(f"未知函数: {name}")

# 执行工具调用
function_result = execute_function(function_name, arguments)

# 将结果回传给模型
second_response = openai.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "北京今天天气怎么样？"},
        message,  # 模型的 function_call 请求
        {
            "role": "tool",
            "tool_call_id": tool_call.id,
            "name": function_name,
            "content": json.dumps(function_result)
        }
    ]
)

# 最终回复
print(second_response.choices[0].message.content)

四、JSON Schema 详解

完整 Schema 结构

支持的参数类型

类型 说明 示例
string 字符串 "city": "北京"
integer 整数 "age": 25
number 浮点数 "price": 19.99
boolean 布尔值 "active": true
array 数组 "tags": ["a", "b"]
object 嵌套对象 "address": {"city": "北京"}
enum 枚举值 "unit": "celsius"

统一封装示例

class FunctionCallingAdapter:
    """统一不同厂商的 Function Calling 接口"""
    
    def __init__(self, provider: str):
        self.provider = provider
    
    def format_tools(self, tools: list) -> dict:
        """格式化工具定义"""
        if self.provider == "openai":
            return {"tools": tools, "tool_choice": "auto"}
        elif self.provider == "google":
            return {
                "tools": [{
                    "function_declarations": [
                        self._convert_to_openapi(t) for t in tools
                    ]
                }]
            }
        # ... 其他厂商
    
    def parse_response(self, response) -> list:
        """统一解析响应"""
        if self.provider == "openai":
            return response.choices[0].message.tool_calls or []
        elif self.provider == "anthropic":
            # Anthropic 的解析逻辑
            pass
    
    def format_result(self, tool_call, result) -> dict:
        """格式化函数结果"""
        return {
            "role": "tool",
            "tool_call_id": tool_call.id,
            "name": tool_call.function.name,
            "content": json.dumps(result)
        }

六、Function Calling 的进阶用法

1. 强制调用指定函数

# 强制调用 get_weather
response = client.chat.completions.create(
    model="gpt-4",
    messages=messages,
    tools=tools,
    tool_choice={"type": "function", "function": {"name": "get_weather"}}
)

2. 禁止调用函数

# 强制不使用工具
response = client.chat.completions.create(
    model="gpt-4",
    messages=messages,
    tools=tools,
    tool_choice="none"  # 禁止调用
)

3. 并行函数调用

# GPT-4 支持一次调用多个函数
# 响应中可能包含多个 tool_call
for tool_call in message.tool_calls:
    function_name = tool_call.function.name
    arguments = json.loads(tool_call.function.arguments)
    # 并行执行所有函数调用

七、常见面试考点

Q1: Function Calling 的完整流程？

答:

  1. 定义工具：用 JSON Schema 描述函数签名
  2. 传递工具：在 API 调用中通过 tools 参数传入
  3. 模型决策：LLM 判断是否需要调用工具
  4. 参数生成：LLM 生成符合 Schema 的参数
  5. 本地执行：应用层执行函数，获取结果
  6. 结果回传：将结果通过 tool 角色回传给模型
  7. 最终回复：模型基于工具结果生成自然语言回复

Q2: Function Calling 和 MCP 的关系？

答: Function Calling 是模型能力（模型决定调用什么函数），MCP 是通信协议（标准化工具连接方式）。MCP 可以在传输层使用 Function Calling 作为实现机制，两者是互补关系。

Q3: 为什么 Function Calling 要使用 JSON Schema？

答: JSON Schema 提供了结构化、标准化的参数描述方式，让 LLM 能够：

  1. 理解每个参数的类型和含义
  2. 生成符合类型要求的参数值
  3. 知道哪些参数是必需的
  4. 从枚举选项中选择合法值

Q4: 如何处理 Function Calling 的错误？

答:

  1. 参数校验：执行前验证参数是否符合 Schema
  2. 超时处理：设置函数执行超时
  3. 错误回传：将错误信息回传给模型，让它决定重试或调整
  4. 降级策略：函数失败时返回默认值或错误提示
