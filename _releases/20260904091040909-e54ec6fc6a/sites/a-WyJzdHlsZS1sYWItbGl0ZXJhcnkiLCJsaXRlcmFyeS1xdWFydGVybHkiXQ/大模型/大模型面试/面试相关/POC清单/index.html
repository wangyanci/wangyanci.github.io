1. 通用问答智能体开发项目

核心开发：

• 设计实现 RAG 智能体核心模块：基于 LangGraph 构建多 Agent 工作流（fetch → query → research_team → final_answer 五节点 DAG），整合 ReAct 推理、向量召回、Rerank重排与流式回答能力

• 优化知识检索、语义理解与答案生成流程，实现智能切片（粗切 + LLM 并行标注 + 位置还原）、向量化召回 + DashScope Rerank 重排 + FAQ 混合打分

• 提供API接口与集成方案，构建 JWT + ServiceToken 双认证，发布可独立调用的 Service API（含三级流控），支持企业多场景快速集成与部署。

2. 财报解析智能体开发

核心开发：

• 设计并实现 5 个核心 Agent（数据预处理、时序审计、指标计算、风险分析、信息收集），通过工作流编排实现多 Agent 协作与数据流转

• 设计双 LLM 并发架构，将 Markdown 报告与 JSON 结构化数据分离到独立 LLM 并发生成

• 实现表达式驱动的财务指标计算引擎，支持多期趋势分析与环比增长率计算

3. 财务报表分析、简历筛选、数字员工等场景开发

核心开发

• 开发智能体系统，实现财务报表数据抽取、指标计算、异常检测及趋势分析。

• 利用 NLP、信息抽取与知识图谱技术，支持财务语义理解与自动化分析报告生成。

• 设计数据处理与模型推理管线，优化系统响应速度和计算资源使用。

• 支持多维度财务分析与预测，为管理决策提供智能支持。

4. 财资智能助手

核心开发/架构师

• 结合数字员工平台实现结算助手和财小资，填写单据、知识问答

• 实现BridgeSDK，可以无侵入的接入业务系统

5. 信贷智防管控项目

核心研发 / 架构师

• 主导贷前尽调模块整体技术架构设计与规划，支撑贷前尽调全业务流程落地；

• 负责贷前尽调技术选型与架构论证，适配尽调数据采集、整合及报告生成需求；

• 主导贷前尽调核心功能研发，完成尽调数据对接、报告模板开发及功能调试；

• 管控贷前尽调模块技术风险，保障尽调数据安全及系统稳定运行；

• 规划贷中监测、贷后预警模块的技术架构，制定后续开发计划及落地路线；

• 推进贷中、贷后相关功能的前期研发筹备，完成技术选型、需求对接及开发方案设计。

6. 大模型底座、智能问数智能体项目

核心研发 / 架构师

• 负责智能问数智能体整体技术架构设计，构建从自然语言理解、意图识别到数据查询与结果生成的端到端技术体系；

• 主导大模型在问数场景中的应用架构设计，包括 Prompt 体系、工具调用（Tool Calling）、多轮对话状态管理与上下文记忆机制；

• 设计并实现智能体核心能力模块，如语义解析、指标与元数据映射、SQL 自动生成与优化、结果解释与可视化输出；

• 负责数据侧架构设计，打通数据仓库、指标体系、元数据管理与权限体系，保障问数结果的准确性、一致性与可追溯性；

• 构建智能体推理与执行框架，支持多模型协同、策略编排与任务调度，提升复杂问数场景下的稳定性与可控性；
