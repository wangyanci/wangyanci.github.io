面试前 Checklist

一、技术准备

核心知识复习

## Agent 基础
- [ ] Agent 定义和四大组件（规划、记忆、工具、行动）
- [ ] ReAct 框架原理（Thought-Action-Observation 循环）
- [ ] CoT / ToT / GoT 推理技术对比
- [ ] Function Calling 完整流程
- [ ] MCP 协议架构（Host-Client-Server）

## RAG 技术
- [ ] RAG 架构和核心组件
- [ ] 文档分块策略
- [ ] Embedding 模型选择
- [ ] 向量数据库对比
- [ ] 检索优化（混合检索、重排序）

## 框架
- [ ] LangChain 核心概念（LCEL、Chain、Agent）
- [ ] CrewAI / AutoGen 多 Agent 框架
- [ ] 各框架的适用场景

## 工程实践
- [ ] 生产级 Agent 设计（状态机、容错、降级）
- [ ] Prompt 工程技巧
- [ ] 模型选型策略
- [ ] 性能优化方法

代码准备

- [ ] 能手写 ReAct Agent 核心逻辑
- [ ] 能写 RAG 流程代码
- [ ] 熟悉 LangChain 基本用法
- [ ] 能手画系统架构图

二、项目复习

项目梳理

## 每个项目准备以下内容：

- [ ] 项目背景（为什么做）
- [ ] 我的职责（我做了什么）
- [ ] 技术方案（怎么做的）
- [ ] 遇到的挑战（如何解决）
- [ ] 量化成果（数据指标）
- [ ] 如果重做会如何改进

三、公司调研

- [ ] 公司主要产品/服务
- [ ] 公司在 AI/Agent 方面的布局
- [ ] 技术栈（从招聘 JD 和开源项目推断）
- [ ] 竞品对比
- [ ] 最新新闻和动态
- [ ] 公司文化和价值观

四、材料准备

- [ ] 简历打印件（2-3份）
- [ ] 身份证
- [ ] 学历证书/证明
- [ ] 作品集/项目 Demo（如有）
- [ ] GitHub 主页整理好
- [ ] 笔记本和笔

五、技术环境准备（线上面试）

- [ ] 网络稳定（有线网络优先）
- [ ] 摄像头和麦克风测试
- [ ] 开发环境就绪（IDE、Python环境）
- [ ] 白板/纸笔（画架构图用）
- [ ] 安静的环境
- [ ] 备用设备（防止意外）

六、心态调整

- [ ] 充足睡眠（面试前一晚）
- [ ] 提前到达（线下提前30分钟，线上提前10分钟）
- [ ] 深呼吸放松
- [ ] 积极的心理暗示
- [ ] 准备好自我介绍（熟练但不背诵）
- [ ] 预设可能的问题并准备答案

七、常见面试题预演

## 基础题
- [ ] 什么是 Agent？和 LLM 的区别？
- [ ] ReAct 框架的原理？
- [ ] CoT 和 ToT 的区别？
- [ ] RAG 的完整流程？
- [ ] Function Calling 的流程？

## 进阶题
- [ ] 如何设计一个生产级 Agent？
- [ ] 如何处理 Agent 的幻觉问题？
- [ ] 多 Agent 系统的协作模式？
- [ ] MCP 和 Function Calling 的关系？
- [ ] RAG 的优化策略有哪些？

## 开放题
- [ ] 设计一个客服 Agent 系统
- [ ] 如何评估 Agent 的效果？
- [ ] Agent 的安全问题如何处理？

八、面试当天流程

## 面试前 1 小时
- [ ] 检查设备和网络（线上面试）
- [ ] 查看交通路线（线下面试）
- [ ] 复习自我介绍
- [ ] 调整心态

## 面试中
- [ ] 保持微笑和眼神交流
- [ ] 听清问题再回答
- [ ] 结构化表达
- [ ] 不懂就诚实说不懂
- [ ] 适当展示思考过程

## 面试后
- [ ] 24 小时内发送感谢邮件/消息
- [ ] 复盘面试表现
- [ ] 记录面试官的问题和反馈
- [ ] 等待结果的同时继续准备其他面试
