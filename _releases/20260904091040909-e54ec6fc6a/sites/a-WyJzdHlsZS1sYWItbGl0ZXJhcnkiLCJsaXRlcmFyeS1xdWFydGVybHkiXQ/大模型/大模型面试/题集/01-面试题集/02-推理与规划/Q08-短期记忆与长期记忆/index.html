短期记忆与长期记忆的设计

问题

请详细解释 AI Agent 中短期记忆和长期记忆的定义、区别、各自的作用，以及如何设计一个工程可用的分层记忆系统。

1. 答案

核心概念：

LLM 本质上是无状态的——每次调用都像一次"短暂失忆"。Memory 系统的本质是为语言模型补上状态管理能力，让 Agent 能够记住过去的信息、积累经验、保持上下文连贯。

记忆的四层分类（基于认知科学）：

  1. 感知记忆（Sensory Memory）：当前输入的原始内容，瞬间处理
  2. 短期记忆 / 工作记忆（Short-term / Working Memory）：当前任务上下文，临时存储
  3. 长期记忆（Long-term Memory）：持久化存储的知识和经验
  4. （可选）程序性记忆（Procedural Memory）："如何做"的技能和规则

短期记忆 vs 长期记忆对比：

维度 短期记忆 长期记忆
存储位置 内存/上下文窗口 外部数据库/向量存储
内容 对话历史、中间状态 用户画像、历史摘要、知识
存取速度 极快 需要检索，较慢
容量 受限于上下文窗口 几乎无限
持久性 会话结束即消失 长期保留
更新频率 每轮更新 按需更新/定期批处理
时间特异性 高（最近信息） 低（宏观抽象理解）

长期记忆的细分：

  1. 情景记忆（Episodic Memory）：记录具体的交互事件和经历
    • 例："用户上周询问了Python的安装方法"
  2. 语义记忆（Semantic Memory）：存储事实性知识和概念
    • 例："用户喜欢使用React技术栈"
  3. 程序性记忆（Procedural Memory）：存储技能和操作流程
    • 例："处理退款请求的标准流程是..."

分层记忆系统设计：

from typing import List, Dict, Optional
import time
from dataclasses import dataclass

@dataclass
class MemoryEntry:
    content: str
    timestamp: float
    importance: float      # 0-1 重要度评分
    source: str            # 来源标记
    memory_type: str       # episodic / semantic / procedural
    embedding: Optional[List[float]] = None

class HierarchicalMemory:
    """分层记忆系统"""
    
    def __init__(self, llm, vector_store, max_context_tokens=8000):
        self.llm = llm
        self.vector_store = vector_store
        
        # 第一层：工作记忆（当前上下文）
        self.working_memory: List[MemoryEntry] = []
        
        # 第二层：短期记忆（最近N轮完整对话）
        self.short_term: List[MemoryEntry] = []
        self.short_term_window = 10  # 保留最近10轮
        
        # 第三层：中期记忆（摘要）
        self.mid_term: List[MemoryEntry] = []
        
        # 第四层：长期记忆（向量数据库）
        self.vector_store = vector_store
        
        self.max_context_tokens = max_context_tokens
    
    def add_interaction(self, user_input: str, agent_output: str):
        """记录一次交互"""
        entry = MemoryEntry(
            content=f"User: {user_input}\nAgent: {agent_output}",
            timestamp=time.time(),
            importance=self._score_importance(user_input, agent_output),
            source="dialogue",
            memory_type="episodic"
        )
        
        # 写入短期记忆
        self.short_term.append(entry)
        
        # 窗口溢出时压缩
        if len(self.short_term) > self.short_term_window:
            old_entries = self.short_term[:5]
            self.short_term = self.short_term[5:]
            self._compress_to_mid_term(old_entries)
    
    def _score_importance(self, user_input: str, agent_output: str) -> float:
        """评估交互重要度"""
        prompt = f"评估以下对话的重要度(0-1):\n用户: {user_input}\n助手: {agent_output}\n重要度:"
        try:
            score = float(self.llm.generate(prompt, max_tokens=5))
            return min(max(score, 0.0), 1.0)
        except:
            return 0.5
    
    def _compress_to_mid_term(self, entries: List[MemoryEntry]):
        """将多条短期记忆压缩为中期摘要"""
        content = "\n".join(e.content for e in entries)
        prompt = f"将以下对话总结为简洁的摘要(保留关键信息):\n{content}\n摘要:"
        summary = self.llm.generate(prompt, max_tokens=200)
        
        summary_entry = MemoryEntry(
            content=summary,
            timestamp=entries[-1].timestamp,
            importance=max(e.importance for e in entries),
            source="summary",
            memory_type="episodic"
        )
        self.mid_term.append(summary_entry)
    
    def retrieve_relevant(self, query: str, top_k: int = 5) -> List[str]:
        """检索相关记忆"""
        results = []
        
        # 1. 从短期记忆中取最近N条
        results.extend([e.content for e in self.short_term[-3:]])
        
        # 2. 从向量数据库检索相关长期记忆
        if self.vector_store:
            long_term_results = self.vector_store.similarity_search(query, k=top_k)
            results.extend(long_term_results)
        
        return results
    
    def persist_to_long_term(self):
        """将中期记忆持久化到长期存储"""
        for entry in self.mid_term:
            if entry.embedding is None:
                entry.embedding = self._get_embedding(entry.content)
            self.vector_store.add(
                embedding=entry.embedding,
                content=entry.content,
                metadata={
                    "timestamp": entry.timestamp,
                    "importance": entry.importance,
                    "type": entry.memory_type
                }
            )
        self.mid_term.clear()
    
    def _get_embedding(self, text: str) -> List[float]:
        """获取文本的 embedding"""
        # 调用 embedding API
        return self.llm.embed(text)
    
    def get_context(self, query: str) -> str:
        """为当前 LLM 调用构建上下文"""
        # 组装：系统指令 + 相关长期记忆 + 中期摘要 + 短期记忆
        relevant = self.retrieve_relevant(query)
        context_parts = []
        
        if relevant:
            context_parts.append("相关背景:\n" + "\n".join(relevant))
        
        context_parts.extend([e.content for e in self.short_term])
        
        return "\n\n".join(context_parts)

2. 延伸追问

  • 追问 1：为什么不直接把历史对话全塞进上下文窗口？答：受限于上下文窗口长度、无关信息会稀释注意力（上下文腐烂）、token 成本高昂。
  • 追问 2：工作记忆和短期记忆的区别？答：工作记忆是当前活跃的任务状态（变量、参数），短期记忆是最近N轮对话历史。
  • 追问 3：记忆系统怎么保证一致性？答：写入时去重、更新时带时间戳、冲突时新信息优先。

3. 常见误区

  • 误区 1：认为上下文窗口越大越好。实际上过长上下文会导致性能退化（上下文腐烂）。
  • 误区 2：所有信息都存长期记忆。实际上应该分级，频繁访问的信息放在更快层。
  • 误区 3：记忆写入不需要筛选。什么都存会导致检索噪声增加、存储膨胀。
