问题

详细描述 MCP 中工具发现（Tool Discovery）和工具调用（Tool Calling）的完整流程。

答案

MCP 的工具发现和调用是其核心工作流程，遵循"先发现、后调用"的契约模式。

工具发现流程（Tool Discovery）

工具发现是 MCP 的初始化阶段，Host 通过 Client 向 Server 获取可用工具列表。

┌──────┐    ┌────────┐    ┌────────┐    ┌────────┐
│ Host │───→│ Client │───→│ Server │───→│ 工具注册表 │
└──────┘    └────────┘    └────────┘    └────────┘
   │            │            │               │
   │ initialize │            │               │
   │───────────→│            │               │
   │            │ initialize │               │
   │            │───────────→│               │
   │            │            │  加载工具定义   │
   │            │            │──────────────→│
   │            │            │←──────────────│
   │            │←──capabilities──│               │
   │←───────────│            │               │
   │            │            │               │
   │ tools/list │            │               │
   │───────────→│            │               │
   │            │ tools/list │               │
   │            │───────────→│               │
   │            │            │  查询工具列表   │
   │            │            │──────────────→│
   │            │            │←──────────────│
   │            │←──tool_list──│               │
   │←──tools────│            │               │

关键步骤详解

1. 初始化（Initialize）

// Client → Server
{
    "jsonrpc": "2.0",
    "id": 0,
    "method": "initialize",
    "params": {
        "protocolVersion": "2024-11-05",
        "capabilities": {
            "sampling": {},
            "roots": {"listChanged": true}
        },
        "clientInfo": {"name": "my-app", "version": "1.0.0"}
    }
}

// Server → Client
{
    "jsonrpc": "2.0",
    "id": 0,
    "result": {
        "protocolVersion": "2024-11-05",
        "capabilities": {
            "tools": {"listChanged": true},
            "resources": {"subscribe": true},
            "prompts": {"listChanged": true}
        },
        "serverInfo": {"name": "my-server", "version": "1.0.0"}
    }
}

2. 工具列表查询（tools/list）

# Client 调用
result = await session.list_tools()

# Server 返回
{
    "jsonrpc": "2.0",
    "id": 1,
    "result": {
        "tools": [
            {
                "name": "read_file",
                "description": "读取指定路径的文本文件内容",
                "inputSchema": {
                    "type": "object",
                    "properties": {
                        "path": {
                            "type": "string",
                            "description": "文件绝对路径"
                        }
                    },
                    "required": ["path"]
                }
            },
            {
                "name": "write_file",
                "description": "将内容写入指定路径的文件",
                "inputSchema": {
                    "type": "object",
                    "properties": {
                        "path": {"type": "string"},
                        "content": {"type": "string"}
                    },
                    "required": ["path", "content"]
                }
            }
        ]
    }
}

3. 工具调用（tools/call）

# Client 调用
result = await session.call_tool("read_file", {"path": "/tmp/data.txt"})

# Server 返回
{
    "jsonrpc": "2.0",
    "id": 2,
    "result": {
        "content": [
            {
                "type": "text",
                "text": "文件内容..."
            }
        ],
        "isError": false
    }
}

动态工具更新

MCP 支持 Server 在运行时动态更新工具列表：

// Server → Client（主动通知）
{
    "jsonrpc": "2.0",
    "method": "notifications/tools/list_changed"
}

// Client 收到通知后重新拉取工具列表
{
    "jsonrpc": "2.0",
    "id": 3,
    "method": "tools/list"
}

完整实现示例

import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
from mcp.types import TextContent

async def mcp_tool_discovery_and_call():
    """MCP 工具发现与调用完整流程"""
    
    server_params = StdioServerParameters(
        command="python",
        args=["mcp_server.py"],
        env=None
    )
    
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            
            # Step 1: 初始化连接
            init_result = await session.initialize()
            print(f"Server 信息: {init_result.serverInfo.name}")
            print(f"Server 能力: {init_result.capabilities}")
            
            # Step 2: 发现工具
            tools_result = await session.list_tools()
            available_tools = {t.name: t for t in tools_result.tools}
            
            print(f"发现 {len(available_tools)} 个工具:")
            for name, tool in available_tools.items():
                print(f"  - {name}: {tool.description}")
            
            # Step 3: 调用工具
            if "read_file" in available_tools:
                call_result = await session.call_tool(
                    "read_file",
                    {"path": "/tmp/test.txt"}
                )
                
                # 解析结果
                for content in call_result.content:
                    if content.type == "text":
                        print(f"文件内容: {content.text}")
                    elif content.type == "image":
                        print(f"图片数据: {content.data[:50]}...")
                
                if call_result.isError:
                    print("工具执行出错")

if __name__ == "__main__":
    asyncio.run(mcp_tool_discovery_and_call())

延伸追问

Q: 工具列表变更时 Client 怎么知道？
A: Server 发送 notifications/tools/list_changed 通知，Client 收到后重新调用 tools/list 获取最新列表。

Q: 工具调用的结果类型有哪些？
A: MCP 支持 text、image、audio、resource 等多种内容类型，通过 content 数组返回。

常见误区

  1. 误区：工具发现只需要做一次。
    纠正：Server 可能动态增删工具，Client 需要监听变更通知。

  2. 误区：工具调用是简单的函数执行。
    纠正：工具调用涉及请求路由、参数校验、权限检查、错误处理、结果格式化等多个环节。

  3. 误区：工具结果只能是文本。
    纠正：MCP 支持图片、音频、二进制数据等多种返回类型。
