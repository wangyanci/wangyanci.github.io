问题

ReAct（Reasoning + Acting）框架是 Agent 领域最重要的设计模式之一。请详细解释其原理、核心循环流程，并用代码示例说明如何实现。

答案

ReAct 概述：

ReAct 来自论文《ReAct: Synergizing Reasoning and Acting in Language Models》（Yao et al., 2023），它将推理（Reasoning）与行动（Acting）交替进行，形成 Thought → Action → Observation 的循环，直到完成任务。

核心思想：让 LLM 边思考边行动，每步都根据上一步的观察结果调整策略。

ReAct 循环的三个核心元素：

  1. Thought（思考）：LLM 分析当前状态，描述观察结果并提出推理，决定下一步做什么
  2. Action（行动）：根据思考结果，选择一个工具并传入参数执行
  3. Observation（观察）：接收工具返回的结果，作为下一步思考的依据
ReAct 循环示意：

用户提问："2024年诺贝尔文学奖得主是谁？他的代表作有哪些？"

Step 1:
  Thought: 我需要查询2024年诺贝尔文学奖得主的信息
  Action: search(query="2024年诺贝尔文学奖得主")
  Observation: "2024年诺贝尔文学奖授予韩国作家韩江（Han Kang）"

Step 2:
  Thought: 已获知获奖者是韩江，现在需要查询她的代表作
  Action: search(query="韩江 代表作 作品")
  Observation: "韩江代表作包括《素食者》《少年来了》《白》等"

Step 3:
  Thought: 我已经获得了足够的信息来回答用户的问题
  Action: finish(answer="2024年诺贝尔文学奖得主是韩国作家韩江...")

完整代码实现：

from typing import List, Dict, Optional
from dataclasses import dataclass

@dataclass
class Tool:
    name: str
    description: str
    func: callable

@dataclass
class ReActStep:
    thought: str
    action: str
    observation: str

class ReActAgent:
    """
    ReAct Agent 核心实现
    Thought → Action → Observation 循环
    """
    
    REACT_PROMPT_TEMPLATE = """你是一个智能助手，可以通过工具来解决问题。
    
可用工具：
{tool_descriptions}

请按照以下格式思考和工作：
Thought: [你对当前情况的分析和推理]
Action: [工具名称, 参数]
Observation: [工具返回结果]

历史步骤：
{history}

用户问题：{question}

当前步骤的 Thought:"""

    def __init__(self, llm_client, tools: List[Tool], max_steps: int = 10):
        self.llm = llm_client
        self.tools = {t.name: t for t in tools}
        self.max_steps = max_steps
        self.history: List[ReActStep] = []
    
    def _format_tool_descriptions(self) -> str:
        """格式化工具描述"""
        return "\n".join([
            f"- {name}: {tool.description}"
            for name, tool in self.tools.items()
        ])
    
    def _format_history(self) -> str:
        """格式化历史步骤"""
        if not self.history:
            return "（无）"
        return "\n".join([
            f"Step {i+1}:\nThought: {step.thought}\n"
            f"Action: {step.action}\nObservation: {step.observation}"
            for i, step in enumerate(self.history)
        ])
    
    def _parse_thought_and_action(self, llm_output: str) -> tuple:
        """解析 LLM 输出的 Thought 和 Action"""
        lines = llm_output.strip().split('\n')
        thought = ""
        action = ""
        
        for line in lines:
            if line.startswith("Thought:"):
                thought = line.replace("Thought:", "").strip()
            elif line.startswith("Action:"):
                action = line.replace("Action:", "").strip()
        
        return thought, action
    
    def _execute_action(self, action: str) -> str:
        """执行工具调用"""
        # 解析 action 格式: "tool_name, param1=value1, param2=value2"
        parts = [p.strip() for p in action.split(",")]
        tool_name = parts[0]
        params = {}
        for p in parts[1:]:
            if "=" in p:
                k, v = p.split("=", 1)
                params[k.strip()] = v.strip()
        
        if tool_name not in self.tools:
            return f"错误：工具 '{tool_name}' 不存在"
        
        try:
            result = self.tools[tool_name].func(**params)
            return str(result)
        except Exception as e:
            return f"工具执行错误：{str(e)}"
    
    def run(self, question: str) -> str:
        """
        执行 ReAct 循环
        """
        for step in range(self.max_steps):
            # 构建 prompt
            prompt = self.REACT_PROMPT_TEMPLATE.format(
                tool_descriptions=self._format_tool_descriptions(),
                history=self._format_history(),
                question=question
            )
            
            # 调用 LLM 生成 Thought
            llm_output = self.llm.generate(prompt)
            thought, action = self._parse_thought_and_action(llm_output)
            
            # 检查是否已完成
            if "finish" in action.lower() or "答案" in action:
                return thought  # 返回答案
            
            # 执行 Action
            observation = self._execute_action(action)
            
            # 记录历史
            self.history.append(ReActStep(
                thought=thought,
                action=action,
                observation=observation
            ))
            
            print(f"Step {step + 1}:")
            print(f"  Thought: {thought}")
            print(f"  Action: {action}")
            print(f"  Observation: {observation[:200]}...")
        
        return "达到最大步数限制"


# ===== 使用示例 =====
def search(query: str) -> str:
    """模拟搜索工具"""
    return f"搜索结果：关于 '{query}' 的相关信息..."

def calculator(expression: str) -> str:
    """模拟计算器工具"""
    try:
        return str(eval(expression))
    except:
        return "计算错误"

# 初始化 Agent
agent = ReActAgent(
    llm_client=llm_client,
    tools=[
        Tool(name="search", description="搜索信息", func=search),
        Tool(name="calculator", description="计算表达式", func=calculator)
    ],
    max_steps=10
)

# 运行
result = agent.run("2024年诺贝尔奖得主是谁？")
print(result)

ReAct 相比纯 CoT（Chain-of-Thought）的优势：

特性 纯 CoT ReAct
外部信息 无法获取 通过工具动态获取
错误修正 推理错误会传播 观察结果可纠正错误
事实验证 依赖训练数据 可实时验证
任务复杂度 适合纯推理题 适合需要外部信息的复杂任务
可解释性 好 更好（思考+行动全过程可见）

延伸追问

  1. 追问：ReAct 中的 Thought 是必须显式输出的吗？

    • 答：不一定。可以显式输出（便于调试和可解释性），也可以隐式内化在 LLM 内部。显式输出更易于人类监督和干预。

  2. 追问：ReAct 的最大步数一般设多少？如何优化效率？

    • 答：通常 10-15 步。优化：①工具描述要精简 ②提供 few-shot 示例 ③设置合理超时 ④对常见任务做 plan 缓存

常见误区

  • 误区：ReAct 是最先进的 Agent 架构，所有场景都应该用
  • 纠正：ReAct 适合工具调用不确定、需要动态调整的场景。对于步骤固定的流程，Plan-and-Execute 更高效
