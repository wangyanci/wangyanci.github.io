问题

AI Agent 按智能水平（或架构复杂度）可以分为哪几类？每种类型的特点、工作原理和典型应用是什么？

答案

Agent 按智能水平从低到高可分为五类，体现了从简单规则响应到自主学习决策的技术演进：

智能水平递进关系：

简单反射 Agent → 基于模型的反射 Agent → 目标驱动 Agent → 效用驱动 Agent → 学习型 Agent
     ↑                    ↑                    ↑               ↑              ↑
   最基础              增加状态记忆          增加规划能力     增加价值评估     增加学习能力

类型一：简单反射型 Agent（Simple Reflex Agent）

  • 原理：基于"条件-动作"规则（if-then），直接根据当前感知信息做出反应
  • 特点：无记忆、无状态、即时响应、规则固定
  • 适用：确定性环境、简单规则任务
  • 典型：自动避障机器人、智能家居开关控制、交通信号灯
class SimpleReflexAgent:
    """简单反射型 Agent"""
    def __init__(self, rules: dict):
        self.rules = rules  # 条件-动作规则表
    
    def act(self, percept) -> str:
        """根据当前感知直接返回动作"""
        for condition, action in self.rules.items():
            if condition(percept):
                return action
        return "default_action"

# 示例：扫地机器人规则
rules = {
    lambda p: p.obstacle_ahead: "turn_right",
    lambda p: p.dirt_detected: "start_cleaning",
    lambda p: p.battery_low: "return_to_dock",
}

类型二：基于模型的反射 Agent（Model-Based Reflex Agent）

  • 原理：在简单反射基础上维护一个内部世界模型，追踪环境状态
  • 特点：有状态记忆、能处理部分可观察环境
  • 适用：需要状态跟踪的场景
  • 典型：自动驾驶汽车（追踪周围车辆位置）、游戏 AI
class ModelBasedAgent:
    """基于模型的反射 Agent"""
    def __init__(self):
        self.internal_model = WorldModel()  # 内部世界模型
    
    def act(self, percept) -> str:
        # 更新内部模型
        self.internal_model.update(percept)
        
        # 基于模型状态决策
        state = self.internal_model.get_current_state()
        return self.rules_based_on_state(state)

类型三：目标驱动型 Agent（Goal-Based Agent）

  • 原理：有明确目标，通过规划和推理选择能达到目标的行动序列
  • 特点：具备规划能力、能展望未来、可处理多步任务
  • 适用：需要目标规划的场景
  • 典型：路径规划机器人、任务调度系统、旅行规划 Agent
class GoalBasedAgent:
    """目标驱动型 Agent"""
    def __init__(self, goal: str):
        self.goal = goal
        self.planner = Planner()
    
    def act(self, percept) -> str:
        # 制定达成目标的计划
        plan = self.planner.create_plan(self.goal, percept)
        # 执行计划的下一步
        return plan.next_action()

类型四：效用驱动型 Agent（Utility-Based Agent）

  • 原理：在目标驱动基础上引入效用函数，评估不同行动的优劣
  • 特点：能权衡多目标、选择最优而非可行方案、处理冲突目标
  • 适用：需要优化决策的场景
  • 典型：推荐系统、资源分配系统、金融投资组合管理
class UtilityBasedAgent:
    """效用驱动型 Agent"""
    def __init__(self, utility_function):
        self.utility_fn = utility_function
    
    def act(self, percept) -> str:
        possible_actions = self.get_possible_actions(percept)
        # 选择效用最高的行动
        best_action = max(possible_actions, 
                         key=lambda a: self.utility_fn(a, percept))
        return best_action

类型五：学习型 Agent（Learning Agent）

  • 原理：能从经验中学习和改进，持续优化决策策略
  • 特点：自适应、持续进化、能从反馈中学习
  • 适用：动态变化环境、需要持续优化的场景
  • 典型：AlphaGo、推荐系统、强化学习游戏 AI
class LearningAgent:
    """学习型 Agent"""
    def __init__(self):
        self.performance_element = PerformanceElement()  # 执行
        self.learning_element = LearningElement()        # 学习
        self.critic = Critic()                           # 评估
        self.problem_generator = ProblemGenerator()      # 探索
    
    def act(self, percept) -> str:
        action = self.performance_element.choose_action(percept)
        return action
    
    def learn(self, feedback):
        """从反馈中学习优化"""
        evaluation = self.critic.evaluate(feedback)
        self.learning_element.improve(evaluation)
        self.performance_element.update(self.learning_element.knowledge)

对比总结表：

类型 记忆 规划 学习 典型应用
简单反射 ❌ ❌ ❌ 自动门、避障机器人
基于模型 ✅ ❌ ❌ 自动驾驶状态跟踪
目标驱动 ✅ ✅ ❌ 导航软件、任务调度
效用驱动 ✅ ✅ ❌ 推荐系统、资源优化
学习型 ✅ ✅ ✅ AlphaGo、智能客服

延伸追问

  1. 追问：LLM-based Agent 属于哪一类？

    • 答：LLM-based Agent 通常是目标驱动 + 学习型的混合体，具备规划能力和一定的从上下文学习中适应的能力。

  2. 追问：实际应用中如何选择 Agent 类型？

    • 答：根据环境复杂度、任务确定性、实时性要求和可用资源综合选择。简单确定环境用反射型，复杂动态环境用学习型。

常见误区

  • 误区：所有 Agent 都需要学习能力
  • 纠正：简单规则明确的场景（如工业控制）使用反射型 Agent 更可靠、更高效
