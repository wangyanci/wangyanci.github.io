问题

请设计一个完整的 Agent Memory 系统，涵盖写入、存储、检索、更新、遗忘全链路，说明每个模块的职责和关键技术选型。

1. 答案

系统架构总览：

┌─────────────────────────────────────────────────────────────┐
│                      Agent Memory System                       │
├──────────┬──────────┬───────────┬──────────┬─────────────────┤
│  写入     │  存储     │  检索      │  更新     │     遗忘        │
│ (Write)  │ (Store)  │ (Retrieve) │ (Update) │   (Forget)      │
├──────────┼──────────┼───────────┼──────────┼─────────────────┤
│Embedding │Vector DB │Embedding  │语义聚类   │多因子评分        │
│  编码    │KV Store  │相似度搜索  │增量摘要   │LRU/LFU          │
│元数据标注│图数据库  │Cross-Enc  │冲突检测   │分层淘汰         │
│触发器    │关系数据库│时间加权   │版本管理   │定期清理         │
└──────────┴──────────┴───────────┴──────────┴─────────────────┘
                         ↕
                    Context Assembly
                    （上下文组装）

全链路实现：

class CompleteMemorySystem:
    """完整的记忆系统"""
    
    def __init__(self, config):
        self.llm = config.llm
        self.embedder = config.embedder
        
        # 存储层
        self.vector_store = config.vector_store   # Milvus/Pinecone
        self.kv_store = config.kv_store           # Redis
        self.graph_db = config.graph_db           # Neo4j
        self.rel_db = config.rel_db               # PostgreSQL
        
        # 子模块
        self.writer = MemoryWriter(self.llm, self.embedder)
        self.retriever = MemoryRetriever(self.vector_store, self.graph_db)
        self.updater = MemoryUpdater(self.llm)
        self.forgetter = MemoryForgetter()
    
    # ========== 写入链路 ==========
    def write(self, content: str, memory_type: str, metadata: Dict = None):
        """
        记忆写入流程:
        1. 生成 Embedding
        2. 提取元数据（时间、重要性、实体等）
        3. 写入对应存储层
        4. 触发更新（如去重、摘要）
        """
        # 1. Embedding
        embedding = self.embedder.embed(content)
        
        # 2. 提取元数据
        entry = MemoryEntry(
            content=content,
            embedding=embedding,
            timestamp=time.time(),
            importance=self.writer.score_importance(content),
            memory_type=memory_type,
            metadata=metadata or {}
        )
        
        # 3. 写入向量库
        memory_id = self.vector_store.add(
            embedding=embedding,
            content=content,
            metadata=entry.to_metadata()
        )
        entry.id = memory_id
        
        # 4. 提取实体关系写入知识图谱
        if memory_type in ("fact", "dialogue"):
            triples = self.writer.extract_triples(content)
            for s, r, o in triples:
                self.graph_db.add_fact(s, r, o, memory_id=memory_id)
        
        # 5. 写入 KV 缓存（热数据）
        self.kv_store.set(f"mem:{memory_id}", entry.serialize(), ttl=3600)
        
        return memory_id
    
    # ========== 检索链路 ==========
    def retrieve(self, query: str, top_k: int = 5, 
                 filters: Dict = None) -> List[MemoryEntry]:
        """
        记忆检索流程:
        1. 查询 Embedding
        2. 粗排（ANN 搜索召回 Top-200）
        3. 精排（Cross-Encoder Rerank）
        4. 时间加权
        5. 返回 Top-K
        """
        # 1. 查询 Embedding
        query_embedding = self.embedder.embed(query)
        
        # 2. 粗排召回
        candidates = self.vector_store.search(
            query_embedding, 
            top_k=200,  # 召回更多做 Rerank
            filters=filters
        )
        
        # 3. 精排（Cross-Encoder）
        reranked = self.retriever.rerank(query, candidates, top_k=50)
        
        # 4. 时间加权（新记忆提升排名）
        time_weighted = self.retriever.apply_time_decay(reranked)
        
        # 5. 返回 Top-K
        return time_weighted[:top_k]
    
    # ========== 更新链路 ==========
    def update(self, memory_id: str, new_content: str = None, 
               metadata_updates: Dict = None):
        """
        记忆更新流程:
        1. 获取原记忆
        2. 检测冲突
        3. 版本管理（旧版本标记过期）
        4. 写入新版本
        """
        old_entry = self.vector_store.get(memory_id)
        
        if new_content:
            # 检测冲突
            conflicts = self.updater.detect_conflicts(new_content, old_entry)
            if conflicts:
                self.updater.archive_old_versions(conflicts)
            
            # 生成新 Embedding
            new_embedding = self.embedder.embed(new_content)
            
            # 更新向量
            self.vector_store.update(
                memory_id,
                embedding=new_embedding,
                content=new_content
            )
        
        if metadata_updates:
            self.vector_store.update_metadata(memory_id, metadata_updates)
    
    # ========== 遗忘链路 ==========
    def forget(self, threshold_days: int = 30):
        """
        记忆遗忘流程:
        1. 扫描所有记忆计算衰减分数
        2. 低分记忆归档
        3. 过期记忆清理
        """
        all_memories = self.vector_store.scan()
        
        for mem in all_memories:
            score = self.forgetter.compute_decay_score(mem)
            
            if score < 0.1:
                # 归档
                self.forgetter.archive(mem)
                self.vector_store.delete(mem.id)
            elif score < 0.3:
                # 降低检索优先级
                self.vector_store.deprioritize(mem.id)
    
    # ========== 上下文组装 ==========
    def assemble_context(self, query: str, max_tokens: int = 4000) -> str:
        """
        为 LLM 调用组装上下文:
        1. 检索相关记忆
        2. 按重要性排序
        3. 在 token 预算内组装
        """
        relevant = self.retrieve(query, top_k=20)
        
        context_parts = []
        current_tokens = 0
        
        for mem in sorted(relevant, key=lambda m: m.importance, reverse=True):
            mem_tokens = len(mem.content) // 4  # 粗略估算
            if current_tokens + mem_tokens > max_tokens:
                break
            context_parts.append(mem.content)
            current_tokens += mem_tokens
        
        return "\n\n---\n\n".join(context_parts)

关键技术选型建议：

模块 推荐方案 备选方案
Embedding BGE-M3（中文）、OpenAI ada-003（英文） E5、M3E
向量数据库 Milvus（大规模）/ Pinecone（托管） Weaviate、Qdrant
KV 缓存 Redis Memcached
知识图谱 Neo4j Nebula Graph
关系数据库 PostgreSQL MySQL
Reranker BGE-Reranker Cross-Encoder
ANN 算法 HNSW（在线）/ IVF+PQ（离线） Flat（小数据）

2. 延伸追问

  • 追问 1：写入链路中的延迟怎么优化？答：Embedding 和元数据提取可以异步化，主链路只写缓存，后台同步到向量库。
  • 追问 2：检索链路中 Reranker 的必要性？答：ANN 召回的粗排精度有限，Reranker 可以提升 Top-K 的相关性 15-30%。
  • 追问 3：记忆系统的监控指标？答：写入延迟、检索延迟、召回率、命中率、存储增长率、冲突率等。

3. 常见误区

  • 误区 1：用一个数据库解决所有问题。实际上不同存储有不同擅长的场景。
  • 误区 2：忽视写入链路的性能。写入如果太慢会影响用户体验。
  • 误区 3：检索只关注相关性。还需要考虑时效性、多样性、可信度等维度。
