## 问题
在向量检索中，余弦相似度（Cosine Similarity）、欧氏距离（Euclidean Distance）和点积（Dot Product）是三种常用的相似度/距离计算方法。它们有什么区别？各适用于什么场景？

## 答案

三种方法是向量检索中最基础的相似度度量方式，核心差异在于**关注点不同**。

**核心概念与公式：**

| 方法 | 公式 | 取值范围 | 关注重点 |
|------|------|---------|---------|
| **点积** | A·B = Σ(a_i × b_i) | (-∞, +∞) | 向量长度 + 方向 |
| **余弦相似度** | cos(θ) = (A·B) / (\|A\| × \|B\|) | [-1, 1] | 仅方向（归一化后的点积） |
| **欧氏距离** | d = √Σ(a_i - b_i)² | [0, +∞) | 空间绝对位置 |

**通俗类比：**

假设两个人在跑步：
- **点积**：衡量"两人跑步的合力效果"——速度越大、方向越一致，点积越大
- **余弦相似度**：只看"两人跑步方向是否一致"——不管速度快慢，方向相同则相似度为 1
- **欧氏距离**：衡量"两人在跑道上的实际距离"——速度差异大、方向不同，距离就大

**深度对比：**

| 对比维度 | 点积 | 余弦相似度 | 欧氏距离 |
|---------|------|-----------|---------|
| 是否受向量长度影响 | 是 | 否 | 是 |
| 是否为距离度量 | 否 | 否（余弦距离是） | 是 |
| 对归一化向量的表现 | 与余弦等价 | 标准使用方式 | 与余弦有单调关系 |
| 计算复杂度 | O(n) | O(n) + 归一化 | O(n) |

**适用场景：**

| 场景 | 推荐方法 | 理由 |
|------|---------|------|
| 文本语义相似度 | **余弦相似度** | 关注语义方向，不关心文本长度 |
| 推荐系统 | **点积** | 向量长度可承载用户偏好强度 |
| 图像特征匹配 | **欧氏距离** | 空间位置差异更重要 |
| 已归一化向量 | **均可** | 归一化后点积=余弦，排序等价 |

**代码示例：**

```python
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

def compute_similarities(a, b):
    """计算三种相似度/距离"""
    a, b = np.array(a), np.array(b)
    
    # 点积
    dot_product = np.dot(a, b)
    
    # 余弦相似度
    cos_sim = cosine_similarity([a], [b])[0][0]
    
    # 欧氏距离
    euclidean = np.linalg.norm(a - b)
    
    return {
        "dot_product": dot_product,
        "cosine_similarity": cos_sim,
        "euclidean_distance": euclidean
    }

# 示例：方向相同但长度不同的向量
a = [1, 2, 3]
b = [2, 4, 6]  # b = 2a，方向完全一致

result = compute_similarities(a, b)
print(f"点积: {result['dot_product']}")           # 28
print(f"余弦相似度: {result['cosine_similarity']}") # 1.0（完全相同方向）
print(f"欧氏距离: {result['euclidean_distance']}") # 3.74（有距离差异）

工程优化：

当向量已做 L2 归一化（模长=1）时：

  • 点积 = 余弦相似度（排序等价）
  • 可省掉归一化计算，加速检索
# 归一化后：点积等价于余弦相似度
from numpy.linalg import norm

normalized_a = a / norm(a)
normalized_b = b / norm(b)

print(np.dot(normalized_a, normalized_b))  # 等同于余弦相似度

延伸追问

Q: 在 RAG 中应该选择哪种相似度？

A: 大多数 RAG 系统使用余弦相似度或点积，因为：

  • 文本语义匹配关注方向而非长度
  • 主流 Embedding 模型输出的向量已归一化，两者等价
  • 向量数据库通常默认使用余弦相似度

Q: 为什么余弦相似度取值范围是 [-1, 1]？

A: 因为余弦相似度等于两个向量夹角的余弦值。夹角 0° 时 cos=1（最相似），90° 时 cos=0（不相关），180° 时 cos=-1（完全相反）。在 NLP 中，由于词向量通常在高维第一象限，实际取值多在 [0, 1]。

常见误区

  1. 点积大就认为相似度高 — 点积受向量长度影响，长向量的点积天然更大
  2. 欧氏距离小就一定相似 — 未归一化时，欧氏距离受长度影响
  3. 三种方法可以互换 — 未归一化向量三种方法排序结果可能不同
  4. 忽略向量数据库的默认相似度 — 不同数据库默认相似度不同，需确认配置
