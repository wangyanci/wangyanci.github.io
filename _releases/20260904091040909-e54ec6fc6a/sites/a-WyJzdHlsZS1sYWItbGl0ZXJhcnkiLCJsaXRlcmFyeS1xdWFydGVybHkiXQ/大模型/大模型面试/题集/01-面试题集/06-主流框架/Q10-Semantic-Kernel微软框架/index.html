Semantic Kernel（微软Agent框架）

问题

请介绍微软Semantic Kernel框架的核心概念（Kernel、Plugin、Planner），以及它与微软新推出的Agent Framework的关系。

答案

Semantic Kernel核心概念

Semantic Kernel（SK）是微软开源的AI开发框架，专注于将LLM能力与现有代码库集成。其设计哲学是"AI与代码的双向融合"——既可以从代码中调用AI能力，也可以让AI调用代码能力。

三大核心抽象：

  1. Kernel（内核）：中央协调器，管理AI服务、插件和记忆

    var builder = Kernel.CreateBuilder();
builder.AddOpenAIChatCompletion("gpt-4", apiKey);
var kernel = builder.Build();

  2. Plugin（插件）：功能封装单元，分为两类

    • Native Functions：原生C#/Python函数，AI可以调用
    • Semantic Functions：基于Prompt的语义函数

  3. Planner（规划器）：自动任务规划组件，将目标分解为执行步骤

    • SequentialPlanner：顺序规划
    • StepwisePlanner：逐步规划（ReAct风格）

代码示例：Semantic Kernel基本使用

import semantic_kernel as sk
from semantic_kernel.connectors.ai.open_ai import OpenAIChatCompletion

# 1. 创建Kernel
kernel = sk.Kernel()
kernel.add_service(OpenAIChatCompletion(service_id="gpt-4", ai_model_id="gpt-4"))

# 2. 定义Semantic Plugin（Prompt函数）
plugin = kernel.create_plugin_from_prompt_directory("Plugins", "WritingPlugin")

# 3. 定义Native Plugin（代码函数）
class MathPlugin:
    @sk.function(name="add")
    def add(self, a: str, b: str) -> str:
        return str(float(a) + float(b))

kernel.add_plugin(MathPlugin(), "MathPlugin")

# 4. 使用Planner自动规划
from semantic_kernel.planning import SequentialPlanner

planner = SequentialPlanner(kernel)
plan = await planner.create_plan("写一篇关于AI安全的博客并计算字数是否超过500")
result = await plan.invoke(kernel)

与Microsoft Agent Framework的关系：

2024年10月，微软推出了新的Microsoft Agent Framework，它是Semantic Kernel和AutoGen的融合进化版：

框架 定位 状态
Semantic Kernel 底层SDK，AI与代码集成 持续维护
AutoGen 多Agent对话框架（微软研究院） 核心能力被吸收
Microsoft Agent Framework 统一的企业级Agent框架 新的主推方向

新框架的四大支柱：

  1. 开放标准：支持MCP、A2A、OpenAPI
  2. 研究管道：AutoGen的多Agent编排模式（群聊、辩论、反思）
  3. 可扩展性：模块化架构，YAML/JSON声明式定义
  4. 生产就绪：OpenTelemetry可观测性、Entra ID认证、CI/CD支持

延伸追问

  • 追问1：Semantic Kernel的Planner与LangChain的Agent有什么区别？
    • 答：SK的Planner更强调"计划先行"——先生成完整执行计划再执行；LangChain的Agent是"边做边想"的ReAct模式。SK的计划更可控，LangChain的Agent更灵活。

常见误区

  • 误区：Semantic Kernel已经被微软放弃了。
  • 纠正：Semantic Kernel仍在持续维护，其能力被整合进新的Microsoft Agent Framework中。对于.NET开发者，SK仍是微软生态的首选Agent SDK。
