LLM 模型选型（GPT-4/Claude/Llama/DeepSeek）的依据是什么？

问题

GPT、Claude、Llama、DeepSeek 等模型各有什么特点？如何根据业务场景选择合适的模型？

答案

一、主流模型选型速查表

选型角度 推荐模型 原因
Agent / 工具调用 / 长任务稳定 Claude (Anthropic) 工具调用稳定，长 CoT 准确率高
通用 + 生态最广 + 多模态 GPT-4o (OpenAI) 生态最完善，Function Calling 成熟
超长上下文 / 多模态 Gemini (Google) 2M 上下文窗口，多模态原生
开源 + 微调研究的事实标准 Llama (Meta) 社区生态最丰富，论文基准
开源 + 推理 / 代码 / 数学 DeepSeek 推理能力强，成本低
中文场景 / 国内私有化 Qwen (阿里) 中文理解好，开源可商用
中文长文档 / 阅读理解 Kimi (Moonshot) 200K 长上下文，中文优化
轻量 / 边缘 / 端侧部署 Mistral / Phi / Gemma 1B-7B 小模型，资源占用少

二、模型选型决策框架

class ModelSelectionFramework:
    """模型选型决策框架"""
    
    DECISION_TREE = {
        "是否需要私有化部署？": {
            "是": {
                "是否有充足 GPU 资源？": {
                    "是": "Llama 3 / Qwen 2.5 / DeepSeek",
                    "否": "Qwen-7B / Mistral-7B (量化部署)"
                }
            },
            "否": {
                "Agent 链路是否 > 5 步？": {
                    "是": "Claude Sonnet (工具调用稳定)",
                    "否": {
                        "是否需要多模态？": {
                            "是": "GPT-4o / Gemini",
                            "否": "GPT-4o-mini (性价比最高)"
                        }
                    }
                }
            }
        }
    }
    
    def evaluate(self, requirements: dict) -> str:
        """根据需求评估最佳模型"""
        if requirements.get("private_deployment"):
            if requirements.get("gpu_budget") > 10:
                return "llama-3.1-70b"
            return "qwen-2.5-7b-int4"
        
        if requirements.get("agent_steps", 0) > 5:
            return "claude-sonnet-4"
        
        return "gpt-4o-mini"

三、实际选型案例

场景 选型 理由
企业内部 Agent，链路 10 步+ Claude Sonnet 工具调用更稳定，长链路准确率高
RAG + 长文档问答 Kimi / Gemini 长上下文成本比切片好控
合规私有化部署 Qwen / DeepSeek 可本地部署，数据不出域
学术研究微调实验 Llama 3 生态丰富，论文对比基准
IoT / 浏览器端 Phi-3 / Gemma-2B 小模型，推理速度快

延伸追问

  • "为什么 Agent 场景推荐 Claude？" — Claude 的工具调用（Function Calling）在长链路中稳定性更高，幻觉率更低
  • "开源模型和闭源模型怎么选？" — 有数据隐私要求选开源，追求效果上限选闭源
