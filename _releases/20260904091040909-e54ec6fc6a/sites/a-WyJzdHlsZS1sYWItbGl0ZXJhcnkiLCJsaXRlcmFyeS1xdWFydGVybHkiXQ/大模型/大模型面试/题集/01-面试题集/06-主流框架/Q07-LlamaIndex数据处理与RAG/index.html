LlamaIndex的数据处理与RAG能力

问题

请详细说明LlamaIndex的技术架构，包括数据连接器、索引构建、查询引擎三大核心模块，以及它在RAG系统中的定位和优势。

答案

LlamaIndex的技术架构

LlamaIndex（现更名为LlamaIndex Core）是一个专注于数据处理和检索增强的框架，其核心目标是将私有数据转化为LLM可用的知识。

四大核心模块：

  1. 数据输入层（Data Connectors）

    • 从多种数据源导入内容：PDF、Word、Markdown、数据库、API、云存储等
    • 支持50+种数据加载器

  2. 数据处理与索引层（Data Processing & Indexing）

    • Node Parser：文档切分为文本块（Chunks）
    • Embedding Model：文本向量化
    • Index：多种索引结构
      • VectorStoreIndex：基于向量相似度的索引（最常用）
      • TreeIndex：树状结构索引，适合层次化查询
      • KeywordTableIndex：关键词索引
      • KnowledgeGraphIndex：知识图谱索引

  3. 查询引擎层（Query Engine）

    • Retriever：检索器，负责从索引中获取相关文档
    • Response Synthesizer：响应合成器，将检索结果和查询组合生成答案
    • 支持多种检索策略：相似度检索、混合检索、多跳检索

  4. 应用层集成（Application Integration）

    • 与LangChain、OpenAI、HuggingFace等框架无缝集成

LlamaIndex在RAG系统中的角色：

RAG系统架构（LlamaIndex视角）
┌──────────────────────────────────────────┐
│           查询引擎 (Query Engine)          │
│    Retriever → Postprocessor → Synthesis  │
└──────────────────┬───────────────────────┘
                   │ 检索Top-K
┌──────────────────▼───────────────────────┐
│           索引层 (Index)                  │
│    VectorStore / Tree / KeywordTable      │
└──────────────────┬───────────────────────┘
                   │ 向量相似度/关键词匹配
┌──────────────────▼───────────────────────┐
│        数据加载层 (Data Connectors)        │
│    PDF / DB / API / Markdown / ...        │
└──────────────────────────────────────────┘

代码示例：完整RAG流程

from llama_index.core import VectorStoreIndex, SimpleDirectoryReader, Settings
from llama_index.core.retrievers import VectorIndexRetriever
from llama_index.core.query_engine import RetrieverQueryEngine
from llama_index.llms.openai import OpenAI
from llama_index.embeddings.openai import OpenAIEmbedding

# 1. 配置模型
Settings.llm = OpenAI(model="gpt-4")
Settings.embed_model = OpenAIEmbedding(model="text-embedding-3-small")

# 2. 数据加载
documents = SimpleDirectoryReader("./data").load_data()

# 3. 构建向量索引（自动完成：切分→Embedding→存储）
index = VectorStoreIndex.from_documents(documents)

# 4. 配置检索器
retriever = VectorIndexRetriever(
    index=index,
    similarity_top_k=5  # 返回Top-5相关文档
)

# 5. 创建查询引擎
query_engine = RetrieverQueryEngine(retriever=retriever)

# 6. 查询
response = query_engine.query("LlamaIndex的核心优势是什么？")
print(response)

# 高级：自定义节点处理器
from llama_index.core.node_parser import SentenceWindowNodeParser

node_parser = SentenceWindowNodeParser.from_defaults(
    window_size=3,
    include_metadata=True
)
index = VectorStoreIndex.from_documents(
    documents,
    transformations=[node_parser]
)

延伸追问

  • 追问1：LlamaIndex的索引类型有哪些？各自适用什么场景？
    • 答：VectorStoreIndex适合语义检索（最通用）；TreeIndex适合层次化总结；KeywordTableIndex适合精确关键词匹配；KnowledgeGraphIndex适合关系型知识查询；ComposableGraph支持多索引组合。
  • 追问2：LlamaIndex与LangChain的RAG实现有什么区别？
    • 答：LlamaIndex更专注于数据侧的优化（多种索引、高级检索策略、自动数据优化），LangChain更侧重于链式编排的灵活性。生产环境中常将LlamaIndex作为Retriever嵌入LangChain/LangGraph的工作流中。

常见误区

  • 误区：LlamaIndex只能做RAG。
  • 纠正：LlamaIndex的能力不仅限于RAG，还包括数据代理（Data Agent）、工具使用、工作流编排等。其Agents可以自主决定如何与数据交互。
