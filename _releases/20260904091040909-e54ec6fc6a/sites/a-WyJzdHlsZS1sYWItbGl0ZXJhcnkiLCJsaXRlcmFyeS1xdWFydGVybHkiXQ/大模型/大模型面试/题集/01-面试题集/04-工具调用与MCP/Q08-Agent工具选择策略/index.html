问题

Agent 如何准确选择应该调用哪个工具？有哪些工具选择的实现策略？

答案

工具选择（Tool Selection）是 Agent 系统的核心能力之一。当工具数量较多时，让 LLM 直接从所有工具中选择效率低且容易出错，需要更智能的选择策略。

工具选择的三种策略

策略一：LLM 直接选择（小工具集）

当工具数量 ≤ 8 个时，直接将所有工具的 Schema 传给 LLM，让模型自行选择。

# 直接选择：所有工具一次性传给 LLM
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": user_query}],
    tools=all_tool_schemas,  # 8个以内的工具
    tool_choice="auto"
)

优点：简单直接，无需额外组件
缺点：工具多了上下文爆炸，选择准确率下降

策略二：检索式工具选择（大工具集）

工具数量很多时，先用检索器筛选出最相关的 K 个工具，再交给 LLM 选择。

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

class ToolRetriever:
    """基于 TF-IDF 的工具检索器"""
    
    def __init__(self, tools: List[dict]):
        self.tools = tools
        self.vectorizer = TfidfVectorizer()
        # 用工具名称+描述构建语料
        corpus = [f"{t['function']['name']} {t['function']['description']}" 
                  for t in tools]
        self.vectors = self.vectorizer.fit_transform(corpus)
    
    def retrieve(self, query: str, top_k: int = 3) -> List[dict]:
        """检索与查询最相关的 K 个工具"""
        query_vec = self.vectorizer.transform([query])
        similarities = cosine_similarity(query_vec, self.vectors)[0]
        
        # 获取 top-k 索引
        top_indices = similarities.argsort()[-top_k:][::-1]
        return [self.tools[i] for i in top_indices]

# 使用示例
retriever = ToolRetriever(all_tools)
relevant_tools = retriever.retrieve("北京今天天气怎么样？", top_k=3)
# relevant_tools 可能包含 [get_weather, web_search, query_location]

优点：

  • 大幅降低上下文长度
  • 工具数量扩展到数百个仍可保持高效
  • 检索准确率高（TF-IDF/BM25/向量检索）

改进方案：多级检索

class HierarchicalToolSelector:
    """分层工具选择器"""
    
    def __init__(self, tools: List[dict]):
        self.tools = tools
        # 按领域分类
        self.categories = {
            "数据查询": [t for t in tools if "query" in t["function"]["name"]],
            "文件操作": [t for t in tools if "file" in t["function"]["name"]],
            "外部API": [t for t in tools if "api" in t["function"]["name"]],
        }
    
    async def select(self, query: str, llm_client) -> List[dict]:
        # 第一层：选择类别
        category_prompt = f"""
        根据用户问题，选择最相关的工具类别：
        用户问题：{query}
        可用类别：{list(self.categories.keys())}
        只返回类别名称，不要解释。
        """
        category = await llm_client.complete(category_prompt)
        
        # 第二层：在类别内选择具体工具
        candidate_tools = self.categories.get(category.strip(), self.tools)
        
        return candidate_tools[:5]  # 返回前5个候选

策略三：Embedding 向量检索（语义匹配）

from sentence_transformers import SentenceTransformer

class SemanticToolRetriever:
    """基于语义向量的工具检索器"""
    
    def __init__(self, tools: List[dict]):
        self.model = SentenceTransformer('BAAI/bge-large-zh-v1.5')
        self.tools = tools
        # 编码工具描述
        descriptions = [t["function"]["description"] for t in tools]
        self.tool_embeddings = self.model.encode(descriptions)
    
    def retrieve(self, query: str, top_k: int = 3) -> List[dict]:
        query_embedding = self.model.encode([query])
        similarities = cosine_similarity(query_embedding, self.tool_embeddings)[0]
        top_indices = similarities.argsort()[-top_k:][::-1]
        return [self.tools[i] for i in top_indices]

工具选择优化技巧

技巧 说明
工具描述优化 描述中明确适用场景和不适用场景
Few-shot 示例 提供工具选择的示例对话
工具分类标签 给工具打标签，便于快速筛选
动态工具集 按会话上下文动态调整可用工具
调用必要性判断 显式加入"不调用工具"的选项

调用必要性判断（防止无意义调用）

# 在工具列表中加入"不调用"选项
no_tool_option = {

        "description": "当用户问题不需要工具就能回答时使用，如闲聊、确认、总结等场景",
        "parameters": {"type": "object", "properties": {}}
    }
}

all_tools_with_option = all_tools + [no_tool_option]

延伸追问

Q: 工具选择准确率怎么评估？
A: 核心指标包括：工具选择准确率、参数有效率、无工具场景误调用率、该调用未调用率。

Q: 工具数量超过 100 个怎么办？
A: 采用多级检索体系——先用 BM25 粗筛到 Top-20，再用语义向量精筛到 Top-5，最后让 LLM 决策。

常见误区

  1. 误区：工具越多越好。
    纠正：工具过多会增加选择难度，应合并相似工具，保持工具集精简。

  2. 误区：只用 LLM 选择就够了。
    纠正：大工具集必须使用检索式预选，否则上下文过长、准确率下降。

  3. 误区：所有场景都给同样的工具集。
    纠正：应按场景动态调整，如客服场景只给客服相关工具。
