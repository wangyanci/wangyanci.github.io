LangGraph构建多智能体工作流

问题

请详细说明如何使用LangGraph构建多智能体工作流，包括状态设计、节点实现、条件路由、并行执行等高级特性。

答案

LangGraph多智能体工作流设计

LangGraph通过状态图（StateGraph）实现多Agent协作，其核心优势在于精细的控制流和状态管理。

多Agent工作流架构：

LangGraph多Agent工作流
┌──────────────────────────────────────────────────┐
│                 Supervisor（调度Agent）            │
│              任务分解 │ 结果汇总 │ 质量控制          │
├──────────────────────────────────────────────────┤
│                                                   │
│   ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│   │ Agent A  │    │ Agent B  │    │ Agent C  │  │
│   │(研究员)  │    │(分析师)  │    │(作家)    │  │
│   └────┬─────┘    └────┬─────┘    └────┬─────┘  │
│        │               │               │         │
│        └───────────────┼───────────────┘         │
│                        ▼                         │
│                ┌──────────────┐                  │
│                │  共享State   │                  │
│                │  (Blackboard)│                  │
│                └──────────────┘                  │
└──────────────────────────────────────────────────┘

完整代码示例：AI研究团队协作系统

from typing import TypedDict, List, Annotated, Literal
from langgraph.graph import StateGraph, END
from langgraph.checkpoint.memory import MemorySaver
from operator import add

# ========== 1. 定义共享状态 ==========
class ResearchState(TypedDict):
    """所有Agent共享的状态"""
    topic: str                    # 研究主题
    search_results: List[str]     # 搜索结果（累加字段）
    analysis: str                 # 分析结果
    report: str                   # 最终报告
    quality_score: float          # 质量评分
    iteration: int                # 迭代次数
    next_step: str                # 下一步决策

# ========== 2. 定义Agent节点 ==========
def research_agent(state: ResearchState):
    """研究Agent：负责信息收集"""
    topic = state["topic"]
    # 模拟搜索（实际调用搜索API）
    results = [
        f"关于{topic}的最新进展1...",
        f"关于{topic}的技术突破2...",
        f"关于{topic}的应用案例3..."
    ]
    return {
        "search_results": results,  # 累加到现有结果
        "iteration": state.get("iteration", 0) + 1
    }

def analysis_agent(state: ResearchState):
    """分析Agent：负责深度分析"""
    results = state["search_results"]
    # 模拟分析
    analysis = f"基于{len(results)}条搜索结果的分析：\n"
    analysis += "1. 技术趋势分析...\n2. 市场影响评估...\n3. 未来发展方向..."
    return {"analysis": analysis}

def writing_agent(state: ResearchState):
    """写作Agent：负责生成报告"""
    analysis = state["analysis"]
    report = f"# 研究报告\n\n{analysis}\n\n## 结论\n基于以上分析..."
    return {"report": report}

def quality_check_agent(state: ResearchState):
    """质量检查Agent"""
    report = state["report"]
    # 模拟质量评分
    score = 0.85 if len(report) > 500 else 0.6
    return {
        "quality_score": score,
        "next_step": "pass" if score >= 0.8 else "revise"
    }

def revision_agent(state: ResearchState):
    """修订Agent：改进报告质量"""
    report = state["report"]
    improved = report + "\n\n## 补充分析\n基于进一步研究..."
    return {"report": improved}

# ========== 3. 条件路由函数 ==========
def route_by_quality(state: ResearchState) -> Literal["pass", "revise"]:
    """根据质量评分决定路由"""
    return state.get("next_step", "pass")

def should_continue(state: ResearchState) -> Literal["continue", "end"]:
    """检查是否需要继续迭代"""
    if state["iteration"] >= 3:
        return "end"
    return "continue"

# ========== 4. 构建工作流图 ==========
workflow = StateGraph(ResearchState)

# 添加节点
workflow.add_node("research", research_agent)
workflow.add_node("analysis", analysis_agent)
workflow.add_node("writing", writing_agent)
workflow.add_node("quality_check", quality_check_agent)
workflow.add_node("revision", revision_agent)

# 设置入口
workflow.set_entry_point("research")

# 添加边
workflow.add_edge("research", "analysis")
workflow.add_edge("analysis", "writing")
workflow.add_edge("writing", "quality_check")

# 条件边：质量检查后的路由
workflow.add_conditional_edges(
    "quality_check",
    route_by_quality,
    {"pass": END, "revise": "revision"}
)

workflow.add_edge("revision", "quality_check")

# ========== 5. 编译并运行 ==========
app = workflow.compile(checkpointer=MemorySaver())

# 执行
result = app.invoke(
    {"topic": "AI Agent技术发展趋势", "search_results": [], "iteration": 0},
    config={"configurable": {"thread_id": "research_001"}}
)

print(f"最终报告:\n{result['report']}")
print(f"质量评分: {result['quality_score']}")

LangGraph多Agent的高级特性：

  1. 并行执行：同一超步骤内的节点自动并行
# 并行执行多个研究Agent
workflow.add_node("research_web", web_research_agent)
workflow.add_node("research_paper", paper_research_agent)
workflow.add_node("research_news", news_research_agent)

# 从同一节点出发的三条边会并行执行
workflow.add_edge("start", "research_web")
workflow.add_edge("start", "research_paper")
workflow.add_edge("start", "research_news")

# 汇聚节点等待所有并行任务完成
workflow.add_edge(["research_web", "research_paper", "research_news"], "synthesize")
  1. Human-in-the-loop：人工审批节点
from langgraph.types import interrupt

def human_approval_node(state: ResearchState):
    """人工审批节点"""
    # 中断执行，等待人工输入
    approval = interrupt({
        "message": "请审查以下报告并决定是否批准:",
        "report": state["report"]
    })
    return {"human_decision": approval}
  1. 子图嵌套：复杂流程模块化
# 将研究工作流封装为子图
research_subgraph = create_research_subgraph()
analysis_subgraph = create_analysis_subgraph()

# 在主图中使用子图
workflow.add_node("research_phase", research_subgraph)
workflow.add_node("analysis_phase", analysis_subgraph)

延伸追问

  • 追问1：LangGraph的状态合并机制是如何工作的？
    • 答：每个节点返回的是一个状态"片段"（Partial State），LangGraph会自动合并到全局状态中。对于列表类型字段，可以使用Annotated+add实现累加而非覆盖。
  • 追问2：LangGraph多Agent工作流的性能优化策略？
    • 答：并行化独立节点；使用异步节点减少IO等待；Checkpoint选择性保存（只保存必要状态）；子图编译缓存；节点结果缓存避免重复计算。

常见误区

  • 误区：LangGraph的节点是真正的独立进程或线程。
  • 纠正：LangGraph节点是Python函数，默认在同一进程中运行。并行执行通过LangGraph的运行时调度实现，不是真正的多进程。对于CPU密集型任务，需要在节点内部自行实现并行。
