CrewAI的角色定义与任务编排

问题

请详细说明CrewAI框架的核心抽象（Agent、Task、Crew、Process），以及它是如何通过角色扮演和流程驱动实现多智能体协作的。

答案

CrewAI的核心理念

CrewAI是一个基于角色扮演（Role-Playing）和流程驱动（Process-Driven）的多智能体协作框架。其设计灵感来源于人类团队协作——每个Agent有明确的角色、目标和背景故事，通过协作完成复杂任务。

四大核心抽象：

  1. Agent（智能体）：具有角色、目标、背景故事的"数字员工"

    • role：角色定义（如"研究员"、"作家"）
    • goal：角色目标（如"收集最新AI信息"）
    • backstory：背景故事（塑造Agent的行为风格）
    • tools：专属工具集
    • allow_delegation：是否允许委派任务

  2. Task（任务）：分配给Agent的具体工作单元

    • description：任务描述
    • expected_output：期望输出格式
    • agent：负责执行的Agent
    • context：依赖的其他任务输出

  3. Crew（团队）：将Agents和Tasks组装成可执行单元

    • 负责整体执行流程管理

  4. Process（流程）：任务分配与执行的策略

    • sequential：顺序执行
    • hierarchical：层级执行（经理Agent委派）

代码示例：构建AI研究团队协作系统

from crewai import Agent, Task, Crew, Process
from langchain_openai import ChatOpenAI

# 定义研究员Agent
researcher = Agent(
    role="高级研究员",
    goal="收集和分析AI Agent领域的最新研究进展",
    backstory="你是一位在AI领域有10年经验的资深研究员，擅长从学术论"
              "文和技术博客中提取关键信息，并形成结构化的研究报告。",
    verbose=True,
    allow_delegation=False,
    tools=[search_tool, scrape_tool],
    llm=ChatOpenAI(model="gpt-4", temperature=0.3)
)

# 定义写作Agent
writer = Agent(
    role="技术作家",
    goal="将研究成果转化为通俗易懂的技术文章",
    backstory="你是一位技术专栏作家，擅长将复杂的技术概念用"
              "简洁生动的语言表达出来，让读者轻松理解。",
    verbose=True,
    allow_delegation=False,
    llm=ChatOpenAI(model="gpt-4", temperature=0.7)
)

# 定义审查Agent
reviewer = Agent(
    role="内容审查员",
    goal="确保文章的技术准确性和表达质量",
    backstory="你是一位严谨的技术编辑，会仔细检查文章中的"
              "每一个技术细节，确保准确无误。",
    verbose=True,
    allow_delegation=False,
    llm=ChatOpenAI(model="gpt-4", temperature=0.2)
)

# 定义任务
research_task = Task(
    description="搜索并整理2024-2025年AI Agent领域的重要进展，"
                "包括新框架、协议和应用案例。输出结构化的研究报告。",
    expected_output="包含以下部分的研究报告：1.新框架发布 2.重要协议 "
                    "3.典型应用案例 4.技术趋势分析",
    agent=researcher
)

writing_task = Task(
    description="基于研究报告撰写一篇技术博客文章，面向AI开发者。",
    expected_output="一篇2000字左右的技术博客，包含引言、正文和总结",
    agent=writer,
    context=[research_task]  # 依赖研究任务的输出
)

review_task = Task(
    description="审查技术博客的技术准确性和表达质量，提出修改建议。",
    expected_output="审查报告，包含技术错误列表和修改建议",
    agent=reviewer,
    context=[writing_task]
)

# 组装团队 - 顺序执行模式
crew = Crew(
    agents=[researcher, writer, reviewer],
    tasks=[research_task, writing_task, review_task],
    process=Process.sequential,  # 顺序执行
    verbose=True
)

# 执行任务
result = crew.kickoff()
print(result)

两种Process模式对比：

模式 说明 适用场景
Sequential 任务按顺序执行，前一个输出作为后一个输入 有明确依赖关系的线性流程
Hierarchical 引入Manager Agent动态委派任务 复杂项目需要统一协调

延伸追问

  • 追问1：CrewAI的context参数如何工作？任务间的数据如何传递？
    • 答：context指定任务依赖关系，被依赖任务的输出会自动作为上下文传递给下游任务。CrewAI内部维护任务输出映射表。
  • 追问2：CrewAI与LangGraph相比各有什么优劣？
    • 答：CrewAI高层抽象、开箱即用，适合快速原型和角色扮演场景；LangGraph更底层、控制更精细，适合需要复杂控制流的生产环境。

常见误区

  • 误区：CrewAI的Agent是独立运行的进程。
  • 纠正：CrewAI的Agent是逻辑抽象，实际运行在Python进程中，通过LLM调用的上下文区分不同角色，而非真正的独立进程。
