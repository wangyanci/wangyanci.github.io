问题

Agent 的反思（Reflection）机制是什么？Reflexion 框架的核心原理和实现方式是什么？为什么反思对 Agent 很重要？

1. 答案

反思机制概述：

反思（Reflection）是 Agent 对自身的工作、输出或决策过程进行评估，并利用评估结果来改进后续行为的机制。它引入了反馈循环，使 Agent 不仅仅生成输出，还会审视该输出，识别问题并优化。

为什么反思很重要：

  1. 自我纠错：发现并修正自己的错误
  2. 持续改进：从失败经验中学习，避免重复犯错
  3. 质量保证：在输出给用户前进行质量检查
  4. 适应性：根据环境反馈调整策略

反思的两种实现模式：

模式一：Basic Reflection（基础反思）

两个独立 Agent 形成闭环：

  • Generator（生成器）：负责产生初始输出
  • Reflector（评估器）：负责批判性评估并提供改进建议
class BasicReflection:
    """基础反思模式：生成器 + 评估器"""
    
    def __init__(self, generator_llm, reflector_llm, max_iterations=3):
        self.generator = generator_llm
        self.reflector = reflector_llm
        self.max_iterations = max_iterations
    
    def run(self, task: str) -> str:
        current_output = self.generator.generate(task)
        
        for i in range(self.max_iterations):
            # 评估器进行批判性评估
            critique = self.reflector.generate(f"""
                原始任务：{task}
                当前输出：{current_output}
                
                请批判性地评估这个输出：
                1. 是否完整回答了问题？
                2. 是否有事实错误？
                3. 是否有遗漏的信息？
                4. 如何改进？
                
                请提供具体的改进建议。
            """)
            
            # 检查是否通过评估
            if "通过" in critique or "完美" in critique:
                break
            
            # 生成器根据反馈改进
            current_output = self.generator.generate(f"""
                原始任务：{task}
                之前的输出：{current_output}
                改进建议：{critique}
                
                请根据建议改进输出。
            """)
        
        return current_output

模式二：Reflexion 框架

来自论文《Reflexion: Language Agents with Verbal Reinforcement Learning》，由三个模块组成：

class ReflexionFramework:
    """
    Reflexion 强化学习框架
    Actor + Evaluator + Self-Reflection
    """
    
    def __init__(self):
        self.actor = Actor()           # 执行者：生成文本和行动
        self.evaluator = Evaluator()   # 评估者：计算奖励分数
        self.self_reflection = SelfReflection()  # 自我反思
        self.reflection_memory = []    # 反思经验库（长期记忆）
    
    def run(self, task: str, max_trials: int = 3) -> str:
        for trial in range(max_trials):
            # 1. Actor 执行任务（参考之前的反思经验）
            trajectory = self.actor.act(
                task=task,
                reflections=self.reflection_memory  # 注入历史反思
            )
            
            # 2. Evaluator 评估轨迹质量
            reward, feedback = self.evaluator.evaluate(task, trajectory)
            
            # 检查是否成功
            if self.is_success(reward):
                return trajectory.final_answer
            
            # 3. Self-Reflection 生成语言化反思
            reflection = self.self_reflection.generate(
                trajectory=trajectory,
                reward=reward,
                feedback=feedback
            )
            
            # 存储反思到长期记忆
            self.reflection_memory.append(reflection)
        
        # 返回最佳尝试的结果
        return trajectory.final_answer
    
    def is_success(self, reward) -> bool:
        """判断任务是否成功"""
        if isinstance(reward, (int, float)):
            return reward >= self.success_threshold
        return reward  # 布尔值

Evaluator 的评估方式（按任务类型）：

任务类型 评估方式
决策任务 启发式规则或环境二元信号（成功/失败）
编程任务 单元测试验证代码正确性
推理任务 基于精确匹配（EM）评分
对话任务 LLM 评估或人工反馈

反思 Prompt 模板：

REFLECTION_PROMPT = """
你正在回顾自己之前的行动，以改进未来的决策。

之前的任务：{task}
你采取的行动：{actions}
结果：{result}
评估反馈：{feedback}

请反思：
1. 你之前的策略有什么问题？
2. 你忽略了什么重要信息？
3. 下次遇到类似情况应该怎么做？

用1-2句话总结你的反思，这个反思将在未来任务中指导你的决策。
"""

反思的应用场景：

  • 代码审查：生成代码后自动检查 bug
  • 论文润色：生成内容后检查质量
  • SQL 检查：生成查询后验证正确性
  • 方案评审：生成方案后评估可行性

2. 延伸追问

  1. 追问：反思和 ReAct 中的 Observation 有什么区别？

    • 答：Observation 是外部工具返回的客观结果；Reflection 是 Agent 对自身行为和结果的主动评估和思考。

  2. 追问：反思会增加多少延迟？如何优化？

    • 答：每次反思需要额外 LLM 调用。优化：①只对关键步骤反思 ②异步反思 ③缓存反思经验复用

3. 常见误区

  • 误区：反思一定会提升性能
  • 纠正：反思的质量取决于评估标准设计。如果评估标准不清晰，反思可能无效甚至引入负向偏差
