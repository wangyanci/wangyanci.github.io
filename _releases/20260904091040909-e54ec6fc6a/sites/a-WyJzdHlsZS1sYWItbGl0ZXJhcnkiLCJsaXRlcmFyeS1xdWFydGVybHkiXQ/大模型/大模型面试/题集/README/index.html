3. 学习路径

3.1. 路径A：应届生 / 初级工程师（0-2年经验）

  1. 打基础：LLM基础MOC → Agent基础概念MOC → 工具调用与MCP MOC
  2. 学应用：RAG技术MOC → 工程实践MOC
  3. 备面试：行为面试MOC + 面试攻略MOC

3.2. 路径B：中级工程师（2-5年经验）

  1. 攻核心：推理与规划MOC → 主流框架MOC → 多智能体系统MOC
  2. 练实战：工程实践MOC → 核心知识MOC
  3. 深项目：准备项目深挖，重点在挑战与解决方案

3.3. 路径C：高级 / 架构师（5年+经验）

  1. 快速通览：全部MOC过一遍，标记薄弱环节
  2. 攻架构：重点 架构模式MOC、对比分析MOC、工程实践MOC
  3. 破系统题：系统设计题攻略 专项突破

4. 面试题覆盖范围

4.1. 核心技术栈

  • Agent 理论：定义、组件、工作循环、分类、设计原则
  • 推理规划：CoT、ToT、GoT、ReAct、Plan-and-Execute、Reflection
  • 记忆机制：短期/长期记忆、向量检索、记忆压缩、知识图谱
  • 工具调用：Function Calling、MCP协议、Schema设计、安全防护
  • RAG 技术：文档切片、Embedding、向量DB、混合检索、GraphRAG
  • 主流框架：LangChain、LangGraph、CrewAI、AutoGen、LlamaIndex、Dify
  • 多智能体：Multi-Agent架构、A2A协议、协作模式、任务分配
  • LLM 基础：Transformer、Attention、位置编码、LoRA、RLHF/DPO

4.2. 工程实践（重点！）

  • 生产环境部署与运维
  • 监控与可观测性（LangSmith、Langfuse）
  • Token 成本控制与优化
  • 安全防护（Prompt注入防御）
  • 幻觉检测与防控
  • 超时处理与降级策略
  • 评估指标体系
  • 性能优化与高并发

4.3. 软技能

  • 自我介绍（1分钟/3分钟版本）
  • 项目介绍（STAR法则）
  • 技术选型阐述
  • 反问问题清单

5. 特色亮点

  1. 每题独立文件：每道面试题是一个独立的 .md 文件，方便在 Obsidian 中快速浏览和链接
  2. Obsidian 原生：完整支持双向链接 [[ ]]、MOC导航、Dataview查询
  3. 难度分级：每道题标注 fundamental / intermediate / advanced 难度
  4. 追问延伸：每道题附带面试官可能的追问及参考答案
  5. 误区纠正：总结面试中的常见错误回答和正确思路
  6. 代码实践：包含完整的 Python 代码示例，可直接运行
  7. Mermaid 图解：关键概念配有 Mermaid 架构图

6. 使用建议

6.1. 在 Obsidian 中打开

  1. 将整个 vault/ 文件夹作为 Obsidian 仓库打开
  2. 安装推荐插件：Dataview、Graph View
  3. 从 总纲MOC 开始导航
  4. 使用 Graph View 查看知识图谱

6.2. 每日复习计划

  • 第1-3天：Agent基础概念（17题）+ LLM基础（8题）
  • 第4-6天：推理与规划（15题）+ Memory机制
  • 第7-8天：工具调用与MCP（18题）
  • 第9-10天：RAG技术（18题）
  • 第11-12天：主流框架（12题）+ 多智能体系统（12题）
  • 第13-14天：工程实践（10题）+ 行为面试（7题）
  • 第15天：核心知识笔记 + 面试攻略
