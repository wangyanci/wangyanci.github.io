智能体开发工程师面试手册

本知识库系统整理AI Agent开发工程师面试的高频考点，覆盖从基础概念到工程实践的完整知识体系。

总计：117道面试题 + 30+核心知识点 + 7份面试攻略

快速导航

一、面试题集

模块 题数 难度 MOC
Agent基础概念MOC 17题 基础~高级 核心定义、组件、ReAct
推理与规划MOC 15题 基础~高级 CoT、ToT、Memory
Memory机制MOC 包含在推理与规划中 - 短期/长期记忆
工具调用与MCP MOC 18题 基础~高级 Function Calling、MCP
RAG技术MOC 18题 基础~高级 向量DB、检索、GraphRAG
主流框架MOC 12题 中级~高级 LangChain、CrewAI、AutoGen
多智能体系统MOC 12题 中级~高级 A2A、协作模式
LLM基础MOC 8题 基础~中级 Transformer、PE、微调
工程实践MOC 10题 中级~高级 部署、监控、安全
行为面试MOC 7题 全级别 STAR法则、项目介绍

二、核心知识

  • 概念解析MOC — Agent、ReAct、MCP、RAG等核心概念
  • 架构模式MOC — 分层设计、协作模式
  • 对比分析MOC — 框架对比、技术选型
  • 代码实践MOC — 完整可运行的代码示例

三、面试攻略

  • 面试攻略MOC — 自我介绍、项目介绍、反问清单、Checklist

学习路径建议

路径A：应届生/初级工程师（0-2年）

  1. LLM基础MOC → Agent基础概念MOC → 工具调用与MCP MOC
  2. RAG技术MOC → 工程实践MOC
  3. 行为面试MOC + 面试攻略MOC

路径B：中级工程师（2-5年）

  1. 推理与规划MOC → 主流框架MOC → 多智能体系统MOC
  2. 工程实践MOC → 核心知识MOC
  3. 项目深挖准备

路径C：高级/架构师（5年+）

  1. 全部MOC快速过一遍
  2. 重点：架构模式MOC、对比分析MOC、工程实践MOC
  3. 系统设计题专项突破
