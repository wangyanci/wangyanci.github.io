自我介绍攻略 (S01)

黄金结构（1-3分钟）

1. 基本信息（10秒）
   "我是XX，XX年毕业于XX大学XX专业"

2. 工作经历（30秒）
   "毕业后先后在XX公司和XX公司工作，主要负责..."

3. Agent 相关经验（60秒）
   "在 Agent 领域，我主导/参与了以下项目：
    - 项目A：XX（技术栈、成果）
    - 项目B：XX（技术栈、成果）"

4. 应聘动机（20秒）
   "我对贵公司的XX业务非常感兴趣，
    希望将我在 Agent 方面的经验应用到..."

项目介绍攻略 (S02)

STAR 法则模板

详见 行为面试MOC

Agent 项目介绍的要点

  1. 业务背景 — 为什么要做这个 Agent？
  2. 技术架构 — 用了什么框架？模型？工具？
  3. 核心挑战 — 遇到的最大技术难题是什么？
  4. 量化成果 — 准确率、延迟、成本、用户满意度
  5. 个人贡献 — 你在其中做了什么？

技术深挖准备 (S03)

Agent 项目常见深挖方向

深挖方向
├── 架构设计
│   ├── 为什么选这个框架？
│   ├── 模型选型的依据？
│   └── 如何评估系统效果？
├── 记忆系统
│   ├── 记忆如何设计？
│   ├── 检索精度如何？
│   └── 如何更新记忆？
├── 工具调用
│   ├── 有哪些工具？
│   ├── 工具如何选择？
│   └── 工具调用失败怎么办？
├── 安全与鲁棒
│   ├── 如何处理幻觉？
│   ├── 如何防御 Prompt 注入？
│   └── 超时和降级策略？
├── 性能与成本
│   ├── Token 成本如何控制？
│   ├── 响应延迟多少？
│   └── 并发处理能力？
└── 迭代优化
    ├── 如何收集 Bad Case？
    ├── 迭代频率和流程？
    └── A/B 测试方案？

反问清单 (S04)

面试结束时的高质量反问：

技术方向

  • "团队目前使用的 Agent 框架和模型是什么？"
  • "Agent 项目目前面临的最大技术挑战是什么？"
  • "团队对 Agent 的评估指标是什么？"

业务方向

  • "Agent 产品在业务中的定位和价值是什么？"
  • "未来半年 Agent 产品的主要目标是什么？"

团队方向

  • "团队的技术氛围和学习机会如何？"
  • "导师制度或新人培养机制是怎样的？"

避免的问题

  • ❌ "我面试通过了吗？"
  • ❌ "加班多吗？"
  • ❌ "薪资能给多少？"

面试 Checklist (S05)

面试前

  • 研究公司背景和业务
  • 复习 Agent基础概念MOC 核心题目
  • 准备 3-5 个项目案例
  • 准备自我介绍（1分钟/3分钟版本）
  • 准备反问清单
  • 测试设备和网络

技术面试

  • 能清晰画出项目架构图
  • 能解释技术选型的理由
  • 准备了核心指标数据
  • 能处理假设性场景题

行为面试

  • 用 STAR 法则准备了案例
  • 案例中有明确的个人贡献
  • 准备了失败案例及反思

面试后

  • 发送感谢邮件
  • 复盘面试表现
  • 记录被问到的新问题
