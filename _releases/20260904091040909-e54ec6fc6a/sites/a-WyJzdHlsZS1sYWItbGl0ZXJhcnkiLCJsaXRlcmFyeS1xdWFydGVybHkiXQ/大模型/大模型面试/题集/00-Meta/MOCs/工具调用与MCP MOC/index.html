工具调用与 MCP MOC

Agent 的工具调用（Tool Use / Function Calling）能力是其与外部世界交互的核心机制。MCP (Model Context Protocol) 是 Anthropic 推出的开放协议，标准化了 AI 模型与工具/数据源之间的连接。共 18 题。

核心概念

  • Function Calling — LLM 输出结构化函数调用指令的能力
  • Tool Use — Agent 选择、调用、处理工具结果的完整流程
  • MCP (Model Context Protocol) — 标准化的模型-上下文连接协议
  • A2A (Agent-to-Agent) — 多 Agent 间的通信协议

MCP 协议速览

MCP (Model Context Protocol)
├── Resources — 只读数据资源
│   ├── 文件系统
│   ├── 数据库
│   └── API 端点
├── Prompts — 可复用提示模板
│   ├── 任务模板
│   └── 角色定义
└── Tools — 可执行工具
    ├── 查询类
    ├── 操作类
    └── 计算类

Function Calling vs MCP 对比

维度 Function Calling MCP
定义方 模型厂商 开放协议 (Anthropic)
工具注册 客户端静态注册 Server 动态暴露
传输方式 单次请求 持久连接 (stdio/sse)
适用场景 简单工具调用 复杂上下文管理
生态 各厂商独立 跨模型统一
