LLM 基础与 Prompt 工程 MOC

Transformer 架构、位置编码、模型选型、微调技术、Prompt Engineering 等 LLM 基础知识。共 8 题。

核心概念

  • Transformer — 自注意力机制驱动的序列建模架构
  • RoPE — 旋转位置编码，处理长序列的关键
  • LoRA/QLoRA — 低秩适配高效微调技术
  • RLHF/DPO — 对齐训练的主流方法
  • Prompt Engineering — 激发 LLM 能力的提示词技巧
