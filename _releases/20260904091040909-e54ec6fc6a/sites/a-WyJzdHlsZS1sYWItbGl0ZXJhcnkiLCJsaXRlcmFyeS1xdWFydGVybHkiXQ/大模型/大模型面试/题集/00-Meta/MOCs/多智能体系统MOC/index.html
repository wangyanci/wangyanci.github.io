多智能体系统 MOC

多智能体系统（Multi-Agent System, MAS）是多个 Agent 协作完成复杂任务的架构范式。涵盖协作模式、通信机制、A2A 协议、CrewAI/AutoGen/LangGraph 实现等。共 12 题。

核心概念

  • Multi-Agent System (MAS) — 多 Agent 协作的分布式智能系统
  • A2A Protocol — Agent-to-Agent 开放通信协议（Google 推出）
  • 协作模式 — 层级式、平等式、竞争式、市场式
  • 任务分解 — 如何将复杂任务拆分为子任务并分配

A2A 协议详解

A2A（Agent-to-Agent Protocol）是 Google 推出的开放协议，用于标准化不同 Agent 之间的通信。

核心能力

  • Capability Discovery — Agent 能力发现
  • Task Management — 任务生命周期管理
  • Collaborative Execution — 协作执行
  • Secure Communication — 安全通信

A2A vs MCP

维度 A2A MCP

多 Agent 协作模式

协作模式
├── 层级式 (Hierarchical)
│   ├── Manager → Worker 结构
│   └── 适合：任务明确的团队管理
├── 平等式 (Peer-to-Peer)
│   ├── 多 Agent 平等协商
│   └── 适合：开放式讨论、头脑风暴
├── 竞争式 (Competitive)
│   ├── 多 Agent 竞争最优解
│   └── 适合：方案评估、择优场景
└── 市场式 (Market-Based)
    ├── 拍卖/竞价机制分配任务
    └── 适合：资源优化、负载均衡
