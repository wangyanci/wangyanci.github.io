主流框架 MOC

主流 Agent 开发框架的深度解析，包括 LangChain/LangGraph、CrewAI、AutoGen、LlamaIndex 等。共 12 题。

框架概览

框架 定位 核心特色 适用场景
LangChain 应用编排框架 Chain/Agent 抽象、生态丰富 快速原型、复杂编排
LangGraph 状态图驱动 循环、条件、持久化状态 复杂工作流、多Agent
CrewAI 角色扮演框架 Role-Based、任务委派 团队协作仿真
AutoGen 对话驱动框架 ConversableAgent、GroupChat 多Agent对话系统
LlamaIndex 数据检索框架 RAG、索引、查询引擎 知识库问答
Dify/Coze 低代码平台 可视化编排、快速上线 无代码/低代码场景
Semantic Kernel 微软官方框架 插件、规划器、多语言 .NET/Python 企业应用
AutoGPT 自主执行实验 自主决策、目标分解 研究探索
