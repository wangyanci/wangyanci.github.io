Memory 机制 MOC

Agent Memory 系统是 Agent 能够持续学习、积累经验、保持上下文连贯性的核心基础设施。本专题覆盖从基础概念到完整架构设计的 8 道面试题。

核心概念

Agent Memory 通常分为三层：

  1. 短期记忆 (STM) — 对话上下文、Scratchpad
  2. 长期记忆 (LTM) — 向量数据库、知识图谱
  3. 外部记忆 — 文件系统、数据库、搜索引擎
