记忆机制设计

一、记忆机制概述

记忆是 Agent 的"经验库"，使 Agent 能够：

  • 保持对话连贯性：记住之前的对话内容
  • 积累知识：从交互中学习和成长
  • 个性化体验：记住用户偏好和习惯
  • 突破上下文限制：超越 LLM 的上下文窗口

三、记忆类型详解

1. 感觉记忆（Sensory Memory）

  • 存储位置：LLM 上下文窗口
  • 容量：极有限（取决于模型上下文长度）
  • 持久性：当前推理步骤
  • 作用：处理当前输入的原始感知

2. 短期记忆（Short-Term Memory, STM）

实现方式：

方式 原理 适用场景
滑动窗口 保留最近 K 轮对话 简单对话
Token 截断 保留最近 N 个 Token 长对话
摘要压缩 定期总结历史对话 超长对话

滑动窗口示例：

class SlidingWindowMemory:
    """滑动窗口短期记忆"""
    
    def __init__(self, max_rounds: int = 10):
        self.max_rounds = max_rounds
        self.messages: list[dict] = []
    
    def add(self, role: str, content: str):
        """添加消息，超出窗口时移除最旧的"""
        self.messages.append({"role": role, "content": content})
        if len(self.messages) > self.max_rounds * 2:  # 用户+助手各算一轮
            self.messages = self.messages[2:]  # 移除最早的一轮
    
    def get_context(self) -> list[dict]:
        """获取当前窗口内的对话历史"""
        return self.messages.copy()

3. 长期记忆（Long-Term Memory, LTM）

长期记忆的存储方式：

类型 存储内容 检索方式
情景记忆 具体事件、对话记录 时间/关键词检索
语义记忆 抽象知识、事实 向量相似度检索
程序记忆 操作流程、偏好 规则匹配/向量检索

四、向量检索记忆系统

核心架构

实现示例

import chromadb
from openai import OpenAI

class VectorMemory:
    """基于向量数据库的长期记忆系统"""
    
    def __init__(self, collection_name: str = "agent_memory"):
        self.client = chromadb.Client()
        self.collection = self.client.get_or_create_collection(
            name=collection_name
        )
        self.embedder = OpenAI()
    
    def _embed(self, text: str) -> list[float]:
        """文本向量化"""
        response = self.embedder.embeddings.create(
            model="text-embedding-3-small",
            input=text
        )
        return response.data[0].embedding
    
    def store(self, content: str, metadata: dict = None):
        """存储记忆"""
        embedding = self._embed(content)
        doc_id = str(hash(content))
        
        self.collection.add(
            embeddings=[embedding],
            documents=[content],
            metadatas=[metadata or {}],
            ids=[doc_id]
        )
    
    def retrieve(
        self, 
        query: str, 
        top_k: int = 5,
        filter_dict: dict = None
    ) -> list[dict]:
        """检索相关记忆"""
        query_embedding = self._embed(query)
        
        results = self.collection.query(
            query_embeddings=[query_embedding],
            n_results=top_k,
            where=filter_dict
        )
        
        memories = []
        for doc, meta, dist in zip(
            results['documents'][0],
            results['metadatas'][0],
            results['distances'][0]
        ):
            memories.append({
                'content': doc,
                'metadata': meta,
                'distance': dist
            })
        
        return memories

五、记忆压缩技术

1. 全量摘要

def summarize_full_history(messages: list, llm) -> str:
    """对完整对话历史进行摘要"""
    history_text = "\n".join([
        f"{m['role']}: {m['content']}" 
        for m in messages
    ])
    
    prompt = f"""请将以下对话历史浓缩为一段简洁的摘要，
保留关键信息和用户偏好：

{history_text}

摘要："""
    
    return llm.generate(prompt)

2. 增量摘要

class IncrementalSummary:
    """增量式记忆摘要"""
    
    def __init__(self, llm):
        self.llm = llm
        self.summary = ""
        self.buffer = []
        self.buffer_size = 10
    
    def add(self, message: dict):
        """添加消息到缓冲区"""
        self.buffer.append(message)
        
        if len(self.buffer) >= self.buffer_size:
            self._flush()
    
    def _flush(self):
        """将缓冲区内容合并到摘要"""
        new_text = "\n".join([
            f"{m['role']}: {m['content']}" 
            for m in self.buffer
        ])
        
        prompt = f"""当前摘要: {self.summary}

新对话: {new_text}

请更新摘要，合并新信息："""
        
        self.summary = self.llm.generate(prompt)
        self.buffer = []
    
    def get_summary(self) -> str:
        """获取当前摘要"""
        if self.buffer:
            self._flush()
        return self.summary

六、记忆管理策略

重要性评估

记忆存储决策流程

class MemoryManager:
    """记忆管理器"""
    
    def __init__(self, llm, vector_memory: VectorMemory):
        self.llm = llm
        self.vector_memory = vector_memory
        self.short_term = SlidingWindowMemory(max_rounds=10)
    
    def assess_importance(self, content: str) -> int:
        """评估信息重要性 (1-10)"""
        prompt = f"""请评估以下信息的重要性（1-10分）：
- 10分：核心身份信息、重要偏好、关键事件
- 7-9分：有用的事实、用户提及的兴趣
- 4-6分：一般性对话内容
- 1-3分：闲聊、临时信息

信息: {content}

只返回数字评分："""
        
        score = int(self.llm.generate(prompt).strip())
        return min(max(score, 1), 10)
    
    def process_message(self, role: str, content: str):
        """处理新消息"""
        # 1. 存入短期记忆
        self.short_term.add(role, content)
        
        # 2. 评估重要性
        importance = self.assess_importance(content)
        
        # 3. 重要信息存入长期记忆
        if importance >= 7:
            self.vector_memory.store(
                content=content,
                metadata={
                    "importance": importance,
                    "role": role,
                    "timestamp": datetime.now().isoformat()
                }
            )
    
    def get_relevant_context(self, query: str) -> str:
        """获取与查询相关的记忆上下文"""
        # 1. 获取短期记忆
        stm = self.short_term.get_context()
        
        # 2. 检索长期记忆
        ltm = self.vector_memory.retrieve(query, top_k=3)
        
        # 3. 组装上下文
        context_parts = []
        
        if ltm:
            context_parts.append("## 相关历史记忆")
            for m in ltm:
                context_parts.append(f"- {m['content']}")
        
        if stm:
            context_parts.append("## 近期对话")
            for m in stm[-6:]:  # 最近3轮
                context_parts.append(f"{m['role']}: {m['content']}")
        
        return "\n".join(context_parts)

指标 说明 目标

八、常见面试考点

Q1: Agent 为什么需要记忆机制？

答:

  1. 突破 LLM 上下文窗口限制
  2. 保持多轮对话的连贯性
  3. 积累用户偏好实现个性化
  4. 从历史交互中学习和优化

Q2: 短期记忆和长期记忆的区别？

答: 短期记忆存储近期对话，容量有限但访问快；长期记忆存储重要信息，容量大、持久化，通过向量检索访问。短期记忆定期归档到长期记忆。

Q3: 如何设计记忆的重要性评估？

答: 可以通过：1) LLM 打分评估信息重要性；2) 用户反馈（显式标记重要）；3) 频次统计（反复提及的话题更重要）；4) 规则匹配（身份信息、偏好等默认高优先级）。

Q4: 向量检索记忆的优势？

答: 向量检索支持语义搜索，能理解同义词和相关概念，不需要精确关键词匹配。配合 Embedding 模型，可以实现基于意义的记忆检索。
