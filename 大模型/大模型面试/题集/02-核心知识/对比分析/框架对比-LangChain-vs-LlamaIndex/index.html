四、代码风格对比

LangChain 风格（LCEL）

from langchain_openai import ChatOpenAI
from langchain.prompts import ChatPromptTemplate
from langchain.output_parsers import StrOutputParser

# LCEL 链式语法
chain = (
    ChatPromptTemplate.from_template("回答以下问题: {question}")
    | ChatOpenAI(model="gpt-4")
    | StrOutputParser()
)

result = chain.invoke({"question": "什么是 Agent?"})

特点：

  • 管道操作符 | 组合组件
  • 声明式、函数式风格
  • 组件可自由组合

LlamaIndex 风格

from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
from llama_index.llms.openai import OpenAI

# 加载文档
 documents = SimpleDirectoryReader("./data").load_data()

# 创建索引
index = VectorStoreIndex.from_documents(documents)

# 创建查询引擎
query_engine = index.as_query_engine(llm=OpenAI(model="gpt-4"))

# 查询
response = query_engine.query("这篇文档讲了什么?")

特点：

  • 面向对象、声明式
  • 数据为中心的设计理念
  • 检索流程内置优化

六、常见面试考点

Q1: LangChain 和 LlamaIndex 的核心区别？

答: LangChain 是通用的 LLM 应用开发框架，侧重 Chain 编排和 Agent 构建；LlamaIndex 专注于数据检索和 RAG，在索引、检索方面更专业。

Q2: 什么时候应该两者结合使用？

答: 当需要构建一个有强大 RAG 能力的 Agent 时，可以用 LlamaIndex 处理数据检索部分，用 LangChain 编排 Agent 的推理和工具调用流程。
