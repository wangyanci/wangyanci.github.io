框架对比：CrewAI vs AutoGen

一、框架定位对比

维度 CrewAI AutoGen
核心定位 角色扮演型多 Agent 协作 对话驱动型多 Agent 编排
设计哲学 团队化、角色化、流程化 对话化、灵活、可编程
主要场景 工作流自动化、团队任务 编程助手、对话式应用
开发团队 João Moura 独立开发 Microsoft Research
发布年份 2023 2023
活跃度 高（社区驱动） 高（微软背书）

三、核心概念对比

概念 CrewAI AutoGen 说明
Agent 定义 Role + Goal + Backstory Name + System Message CrewAI 更角色化
任务定义 Task (描述 + 期望输出) 隐含在对话中 CrewAI 更结构化
协作模式 Process (Hierarchical/Sequential) GroupChat / Two-Agent AutoGen 更灵活
工具使用 @tool 装饰器 register_function 都支持函数工具
人类介入 Human Input 参数 UserProxyAgent AutoGen 更原生
对话管理 通过 Process 控制 GroupChatManager AutoGen 更强
代码执行 需自行集成 内置 CodeExecutor AutoGen 更强大

四、代码风格对比

CrewAI 代码风格

from crewai import Agent, Task, Crew

# 定义 Agent（角色扮演风格）
researcher = Agent(
    role='研究员',
    goal='深入研究主题并收集关键信息',
    backstory='你是一位资深研究员，擅长信息检索和分析',
    verbose=True,
    allow_delegation=False,
    tools=[search_tool]
)

writer = Agent(
    role='写作专家',
    goal='将研究内容转化为高质量文章',
    backstory='你是一位专业作家，擅长将复杂信息简化',
    verbose=True
)

# 定义任务
task1 = Task(
    description='研究 {topic} 的最新进展',
    expected_output='一份详细的研究报告',
    agent=researcher
)

task2 = Task(
    description='基于研究报告撰写文章',
    expected_output='一篇 1000 字的文章',
    agent=writer,
    context=[task1]
)

# 创建团队
crew = Crew(
    agents=[researcher, writer],
    tasks=[task1, task2],
    process='sequential'  # 顺序执行
)

result = crew.kickoff(inputs={'topic': 'AI Agent'})

特点：

  • 角色驱动（Role/Goal/Backstory）
  • 任务显式定义
  • 流程化协作
  • 更像"团队管理"

AutoGen 代码风格

import autogen

# 配置 LLM
config_list = [
    {
        "model": "gpt-4",
        "api_key": "your-key"
    }
]

# 定义 Agent（对话风格）
assistant = autogen.AssistantAgent(
    name="assistant",
    llm_config={"config_list": config_list},
    system_message="你是一位有用的 AI 助手。"
)

user_proxy = autogen.UserProxyAgent(
    name="user_proxy",
    human_input_mode="NEVER",
    max_consecutive_auto_reply=10,
    code_execution_config={"work_dir": "coding"},
    llm_config={"config_list": config_list}
)

# 发起对话
user_proxy.initiate_chat(
    assistant,
    message="请帮我写一个 Python 函数，计算斐波那契数列"
)

特点：

  • 对话驱动
  • 内置代码执行
  • 灵活的多 Agent 编排
  • 更像"群聊"

六、选择建议

选择 CrewAI 的场景

  • 需要明确的角色分工（研究员、程序员、测试员等）
  • 工作流可以预先定义（顺序/层级执行）
  • 团队更喜欢结构化的开发方式
  • 需要快速上手，学习曲线平缓
  • 任务有明确的输入输出定义

选择 AutoGen 的场景

  • 需要动态对话和灵活编排
  • Agent 需要执行代码（特别是编程助手）
  • 需要复杂的多轮对话管理
  • 需要人类在循环中灵活介入
  • 对灵活性和可定制性要求高

混合使用建议

# 可以用 CrewAI 管理整体工作流
# 用 AutoGen 处理需要对话的子任务

# CrewAI 负责高层任务分配
crew = Crew(
    agents=[manager, coder],
    tasks=[plan_task, code_task],
    process='hierarchical'
)

# code_task 内部使用 AutoGen 处理复杂编程对话

七、常见面试考点

Q1: CrewAI 和 AutoGen 的核心区别？

答: CrewAI 是角色扮演型的多 Agent 框架，强调角色定义和流程化协作；AutoGen 是对话驱动的多 Agent 框架，强调 Agent 间的灵活对话和代码执行能力。

Q2: 什么时候选择 CrewAI，什么时候选择 AutoGen？

答: 需要结构化角色分工选 CrewAI；需要动态对话和代码执行选 AutoGen。两者也可以结合使用。
